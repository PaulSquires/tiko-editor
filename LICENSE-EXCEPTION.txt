Note on removing the proprietary components:

The GPL-licensed portion of tiko is a complete, working code editor without
fbcParser and debugParser. Removing them disables symbol-driven code
intelligence (code tips, autocompletion, Go To Definition, the symbol
panels) and the integrated debugger. Editing, building, project management,
theming, and everything else continue to function. A fork that wishes to
carry no proprietary code at all may therefore drop them and remains fully
distributable under the GPL alone.
