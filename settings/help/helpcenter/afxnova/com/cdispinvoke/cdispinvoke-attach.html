CDispInvoke.Attachmethod

Attaches a Dispatch pointer.

COMmethodCDispInvoke.incdocumented

Syntax

FUNCTION Attach (BYVAL pdisp AS IDispatch PTR, BYVAL fAddRef AS BOOLEAN = FALSE) AS HRESULT

Parameters

NameDescription
pdispPointer to a Dispatch interface,
fAddRefIf it is false, the object takes ownership of the interface pointer without calling AddRef.
If it is true, then AddRef is called. This is needed when we pass a raw pointer.

Description

Attaches a Dispatch pointer to the class.
