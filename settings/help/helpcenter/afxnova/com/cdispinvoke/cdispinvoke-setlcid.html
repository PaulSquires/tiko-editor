CDispInvoke.SetLcidmethod

Sets the locale identifier used by the class.

COMmethodCDispInvoke.incdocumented

Syntax

FUNCTION SetLcid (BYVAL lcid AS LCID)

Parameters

NameDescription
lcidThe locale context in which to interpret arguments. The lcid is used by the GetIDsOfNames function, and is also passed to Invoke to allow the object to interpret its arguments specific to a locale. Applications that do not support multiple national languages can ignore this parameter.

Description

Sets de locale identifier used by the class.
