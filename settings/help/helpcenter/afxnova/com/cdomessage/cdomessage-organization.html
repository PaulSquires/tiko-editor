CDOMessage.Organizationmethod

The organization of the sender.

COMmethodCDOMessage.incdocumented

Syntax

FUNCTION Organization (BYREF wszOrganization AS WSTRING) AS HRESULT

Parameters

NameDescription
wszOrganizationThe Organization property is used for the Network News Transfer Protocol (NNTP) Organization header field. This field supplies a short phrase that meaningfully describes the sender's organization, such as "Sample Corporation, Payroll Department". A phrase such as this can be easier to recognize than a cryptic messaging address like "Q1006453@example.com"

The default value of the Organization property is an empty string.

Return value

S_OK (0) or an HRESULT code.

Description

The organization of the sender.
