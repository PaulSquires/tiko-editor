CDOMessage.Sendermethod

The messaging address of the message submitter.

COMmethodCDOMessage.incdocumented

Syntax

FUNCTION Sender (BYREF wszSender AS WSTRING) AS HRESULT

Parameters

NameDescription
wszSenderThe difference between the From and Sender properties is that the Sender property identifies the address of the user or entity that actually submits the message, whereas the From property designates its principal author or authors. By convention, which is outlined in Request for Comments (RFC) 822, multiple addressees are not identified in the Sender property.

The Sender property is normally used under the following circumstances:

Multiple addressees are listed in the From header. The sender is the e-mail address of the user or entity in the From field that actually submitted the message.

The user or entity that is submitting the message is not included in the From field.

Return value

S_OK (0) or an HRESULT code.

Description

The messaging address of the message submitter.
