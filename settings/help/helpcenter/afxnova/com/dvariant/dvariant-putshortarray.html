Initializes DVARIANT from an array of signed 16-bit integer values.

Parameters

NameDescription

If this function succeeds, it returns S_OK (0). Otherwise, it returns an HRESULT error code.

Description

Initializes DVARIANT from an array of signed 16-bit integer values.
