CADOFields.Delete_method

Deletes an object from the `Fields` collection.

DatabasesmethodCADOFields.incdocumented

Syntax

FUNCTION Delete_ (BYREF dvIndex AS DVARIANT) AS HRESULT

Parameters

NameDescription
dvIndexA Variant that designates the Field object to delete. This parameter can be the name of the Field object or the ordinal position of the Field object itself.

Return value

S_OK (0) or an HRESULT code.

Description

Deletes an object from the Fields collection.

Remarks

Calling the Delete_ method on an open Recordset causes a run-time error.
