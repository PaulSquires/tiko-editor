CPowerTime.AstroDaymethod

Returns the Astronomical Day for any given date.

DateTimemethoddocumented

Syntax

FUNCTION AstroDay () AS LONG
FUNCTION AstroDay (BYVAL nYear AS LONG, BYVAL nMonth AS LONG, BYVAL nDay AS LONG) AS LONG

Parameters

NameDescription
nYearA four digit year.
nMonthA month number (1-12).
nDayA day number (1-31).

Return value

The astronomical day.

Description

Returns the Astronomical Day for this CPowerTime object.

Returns the Astronomical Day for any given date.

Remarks

Among other things, can be used to find the number of days between any two dates, e.g.:

Example

DIM cpt AS CPowerTime PRINT cpt.AstroDay(-12400, 3, 1) - cpt.AstroDay(-12400, 2, 28) ' Prints 2 PRINT cpt.AstroDay(12000, 3, 1) - cpt.AstroDay(-12000, 2, 28) ' Prints 8765822 PRINT cpt.AstroDay(1902, 2, 28) - cpt.AstroDay(1898, 3, 1) ' Prints 1459 days
