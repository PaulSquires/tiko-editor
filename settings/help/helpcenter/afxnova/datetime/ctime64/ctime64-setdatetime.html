CTime64.SetDateTimemethod

Sets the date and time of this **CTime64** object.

DateTimemethodCTime64.incdocumented

Syntax

FUNCTION SetDateTime (BYVAL nYear AS WORD, BYVAL nMonth AS WORD, BYVAL nDay AS WORD, BYVAL nHour AS WORD = 0, BYVAL nMin AS WORD = 0, BYVAL nSec AS WORD = 0) AS BOOLEAN

Parameters

NameDescription
nYearThe year (1970-3000).
nMonthThe month (1-12).
nDayThe day (1-31).
nHourThe hour (0-23).
nMinuteThe minutes (0-59).
nHourThe seconds (0-59).

Description

Sets the date and time of this CTime64 object.

Example

' // Year = 2017, Month = 10 (October), Day = 9, Hour = 11, Minutes = 32, Seconds = 45 DIM ct AS CTime64 = CTime64(2017, 10, 9, 11, 32, 45)
