CExplorerBrowser.BrowseToIDListmethod

File Managementmethoddocumented

Syntax

FUNCTION BrowseToIDList (BYVAL pidl AS LPCITEMIDLIST, BYVAL uFlags AS UINT) AS HRESULT
Also documented as BroseToIDList — one description covers them all.

Parameters

NameDescription
pidlType: PCUIDLIST_RELATIVE. A pointer to a const ITEMIDLIST (item identifier list) that specifies an object's location as the destination to navigate to. This parameter can be NULL.
uFlagsA flag that specifies the category of the pidl. This affects how navigation is accomplished. Must be the value zero, or a bitwise combination of the following values.

Return value

If this method succeeds, it returns S_OK. Otherwise, it returns an HRESULT error code.

Description

Browses to a pointer to an item identifier list (PIDL)

Remarks

The parameter pidl may be NULL if the flags specified in uFlags indicate navigation through the built-in TravelLog, that is, SBSP_NAVIGATEBACK or SBSP_NAVIGATEFORWARD.

This method supports only a subset of the SBSP flags listed in the shobjidl.bi file. Consequently, this method returns E_INVALIDARG if SBSP_NEWBROWSER or SBSP_EXPLOREMODE are specified in uFlags.
