ppvWhen this method returns, contains the interface pointer requested in riid. This will typically be IShellView, IShellView2, IFolderView, or a related interface.

Return value

First overloaded method: If this method succeeds, it returns S_OK. Otherwise, it returns an HRESULT error code.
