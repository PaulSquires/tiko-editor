CExplorerBrowser.SetFolderSettingsmethod

Sets the folder settings for the current view.

File Managementmethoddocumented

Syntax

FUNCTION SetFolderSettings (BYVAL pfs AS FOLDERSETTINGS PTR) AS HRESULT
FUNCTION SetFolderSettings (BYVAL ViewMode AS UINT, BYVAL fFlags AS UINT) AS HRESULT

Parameters

NameDescription
pfsA pointer to a FOLDERSETTINGS structure that contains the folder settings to be applied.
ViewModeFolder view mode. One of the FOLDERVIEWMODE values.
fFlagsA set of flags that indicate the options for the folder. This can be zero or a combination of the FOLDERFLAGS values.

Return value

If this method succeeds, it returns S_OK. Otherwise, it returns an HRESULT error code.

Description

Sets the folder settings for the current view.

Remarks

This method also changes the default that will be applied when navigating to another location.

To ensure the view state is preserved across sessions, specify the persistence name using SetPropertyBag.
