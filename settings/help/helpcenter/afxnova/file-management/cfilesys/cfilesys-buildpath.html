CFileSys.BuildPathmethod

Appends a name to an existing path.

File ManagementmethodCFileSys.incdocumented

Syntax

FUNCTION BuildPath (BYREF wszPath AS WSTRING, BYREF wszName AS WSTRING) AS DWSTRING

Parameters

NameDescription
wszPathExisting path to which name is appended. Path can be absolute or relative and need not specify an existing folder.
wszNameName being appended to the existing path.

Return value

The new path.

Description

Appends a name to an existing path.

Remarks

The BuildPath method inserts an additional path separator between the existing path and the name, only if necessary.

Examples

#INCLUDE ONCE "AfxNova/CFileSys.inc" DIM pFileSys AS CFileSys DIM dwsNewPath AS DWSTRING = pFileSys.BuildPath("C:\MyFolder", "Text.txt") ' Output: C:\MyFolder\Text.txt

CFileSys().BuildPath("C:\MyFolder", "Text.txt")
