CFileSys.GetDriveTotalSizemethod

Returns the total space, in bytes, of a drive or network share.

File ManagementmethodCFileSys.incdocumented

Syntax

FUNCTION GetDriveTotalSize (BYREF wszDrive AS WSTRING) AS DOUBLE

Parameters

NameDescription
wszDriveCBSTR. The drive letter. For drive letters, the root drive is not included. For example, the path for the C drive is C:, not C:\\.

Return value

DOUBLE. The total space in bytes.

Description

Returns the total space, in bytes, of a drive or network share.

Example

#INCLUDE ONCE "AfxNova/CFileSys.inc" DIM pFileSys AS CFileSys PRINT pFileSys.GetDriveTotalSize("C:")
