CIniFile.GetSectionValuesmethod

Returns the keys and values of the specified section as a dictionary object.

File ManagementmethodCIniFile.incdocumented

Syntax

FUNCTION GetSectionValues (BYREF wszSectionName AS WSTRING, BYREF pDic AS CDicObj) AS BOOLEAN

Parameters

NameDescription
wszSectionNameThe name of the section.
pDicA reference to an instance of the CDicObj class.

Return value

BOOLEAN. True on success or False on failure.

Description

Returns the keys and values of the specified section as a dictionary object.

Examples

DIM pDic AS CDicObj IF cIni.GetSectionValues("Test", pDic) THEN print pDic.Item("Name") END IF

DIM pDic AS CDicObj IF cIni.GetSectionValues("Test", pDic) THEN ' // Get all the keys and display them DIM dvKeys AS DVARIANT = pDic.Keys FOR i AS LONG = dvKeys.GetLBound TO dvKeys.GetUBound

print dvKeys.GetVariantElement(i)

NEXT ' // Get all the items and display them DIM dvItems AS DVARIANT = pDic.Items FOR i AS LONG = dvItems.GetLBound TO dvItems.GetUBound

print dvItems.GetVariantElement(i)

NEXT END IF
