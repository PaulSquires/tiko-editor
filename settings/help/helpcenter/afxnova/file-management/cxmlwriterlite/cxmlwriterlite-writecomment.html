CXmlWriterLite.WriteCommentmethod

Writes out a comment that contains the specified text.

File Managementmethoddocumented

Syntax

FUNCTION WriteComment (BYVAL pwszComment AS LPCWSTR) AS HRESULT

Parameters

NameDescription
pwszCommentThe text of the comment. NULL is equivalent to an empty string.

Return value

Returns S_OK if no error is generated.

Description

Writes out a comment that contains the specified text.

Remarks

This method produces a comment in the following format, where text is the text provided: If the text block provided contains the characters "-->", which denote the end of a comment, this method will insert a space between the two "-" characters. This change to the text prevents the writer from producing an XML document that is not well-formed.

If the pwszComment parameter is NULL, the writer produces a comment that does not contain any text.
