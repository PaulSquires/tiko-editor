CImageCtx.SetInterpolationModemethod

Sets the interpolation mode used by GDI+.

Graphicsmethoddocumented

Syntax

SUB SetInterpolationMode (BYVAL InterpolationMode AS LONG)

Parameters

NameDescription
InterpolationModeThe interpolation mode. Should be one of the following values:

Return value

The previous setting value.

Description

Sets the interpolation mode used by GDI+. The interpolation mode determines the algorithm that is used when images are scaled or rotated.

Example

InterpolationModeInvalid = -1 InterpolationModeDefault = 0 InterpolationModeLowQuality = 1 InterpolationModeHighQuality = 2 InterpolationModeBilinear = 3 InterpolationModeBicubic = 4 InterpolationModeNearestNeighbor = 5 InterpolationModeHighQualityBilinear = 6 InterpolationModeHighQualityBicubic = 7
