CGpBase.PWMFRect16method

Defines a rectangle that bounds a placeable metafile.

Description

The PWMFRect16 structure defines a rectangle that bounds a placeable metafile. The rectangle defines the size and position of the metafile.

Example

TYPE PWMFRect16 Left AS INT16 Top AS INT16 Right AS INT16 Bottom AS INT16 END TYPE
