CGpBrush.GetTypemethod

Gets the type of this brush.

GraphicsmethodCGpBrush.incdocumented

Syntax

FUNCTION GetType () AS GpBrushType

Return value

This method returns the type of this brush. The value returned is one of the elements of the BrushType enumeration.

Description

Gets the type of this brush.

Example

' ======================================================================================== ' The following example creates a SolidBrush object, checks the type of the object, and ' then, if the type is BrushTypeSolidColor, uses the brush to fill a rectangle. ' ======================================================================================== SUB Example_GetType (BYVAL hdc AS HDC)

' // Create a graphics object from the window device context DIM graphics AS CGpGraphics = hdc ' // Set the scale transform graphics.ScaleTransformFordpi

' // Create a SolidBrush object DIM solidBrush AS CGpSolidBrush = ARGB_BLUE

' // Get the type of solidBrush DIM nType AS BrushType = solidBrush.GetType

' // If the type of solidBrush is BrushTypeSolidColor, use it to fill a rectangle IF nType = BrushTypeSolidColor THEN

graphics.FillRectangle(@solidBrush, 0, 0, 100, 100)

END IF

END SUB ' ========================================================================================
