CGpImage.GetPropertyItemSizemethod

Gets the size, in bytes, of a specified property item of the Image object.

GraphicsmethodCGpBitmap.incdocumented

Syntax

FUNCTION GetPropertyItemSize (BYVAL propId AS PROPID) AS UINT

Parameters

NameDescription
propIdInteger that identifies the property item.

Description

Gets the size, in bytes, of a specified property item of an Image object.

Example

'#CONSOLE ON #define _WIN32_WINNT &h0602 #INCLUDE ONCE "AfxNova/CGdiPlus.inc" USING AfxNova

' ======================================================================================== ' Gets a specified property item (piece of metadata) from an image. ' ========================================================================================

' // Create a Bitmap object from a JPEG file. DIM image AS CGpImage = "climber.jpg"

' // Get the size of the specified property item. DIM itemSize AS UINT = image.GetPropertyItemSize(PropertyTagLuminanceTable)
