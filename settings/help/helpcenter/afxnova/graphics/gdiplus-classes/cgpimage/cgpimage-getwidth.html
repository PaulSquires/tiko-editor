CGpImage.GetWidthmethod

Gets the width, in pixels, of the image.

GraphicsmethodCGpBitmap.incdocumented

Syntax

FUNCTION GetWidth () AS UINT

Description

Gets the width, in pixels, of the image.

Example

'#CONSOLE ON #define _WIN32_WINNT &h0602 #INCLUDE ONCE "AfxNova/CGdiPlus.inc" USING AfxNova

' ======================================================================================== ' The following example retrieves the width of an image. ' ========================================================================================

' // Create a Bitmap object from a JPEG file. DIM image AS CGpImage = "climber.jpg"

' // Get the width of the image DIM nWidth AS UINT = image.GetWidth PRINT "Image width: " & WSTR(nWidth)

PRINT PRINT "Press any key" SLEEP
