GdipDeleteMatrixfunction

Deletes the specified **Matrix** object.

Graphicsfunctiondocumented

Syntax

FUNCTION GdipDeleteMatrix (BYVAL matrix AS GpMatrix PTR) AS GpStatus

Parameters

NameDescription
matrix[in] Pointer to the Matrix object.

Description

Deletes the specified Matrix object.

Example

DIM matrix AS GpMatrix PTR hStatus = GdipCreateMatrix2(3, 0, 0, 1, 0, 0, @matrix) ... ... ... IF matrix THEN GdipDeleteMatrix(matrix)
