GdipDeleteRegionfunction

Deletes a **Region** object.

Graphicsfunctiondocumented

Syntax

FUNCTION GdipDeleteRegion (BYVAL region AS GpRegion PTR) AS GpStatus

Parameters

NameDescription
region[in] Pointer to the Region object.

Description

Deletes a Region object.

Example

' // Create a graphics object from the device context DIM graphics AS GpGraphics PTR GdipCreateFromHDC(hdc, @graphics)

' // Create a rectangular region. DIM rectRegion AS GpRegion PTR DIM rcf AS GpRectF = (65, 15, 70, 45) GdipCreateRegionRect(@rcf, @rectRegion)

' ... ' ... ' ...

' // Cleanup IF rectRegion THEN GdipDeleteRegion(rectRegion) IF graphics THEN GdipDeleteGraphics(graphics)
