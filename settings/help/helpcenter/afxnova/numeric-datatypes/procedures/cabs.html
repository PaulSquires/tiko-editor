CAbsfunction

Returns the magnitude of a complex number.

Numeric DatatypesfunctionAfxComplex.incdocumented

Syntax

FUNCTION CAbs (BYREF z AS _complex) AS DOUBLE
Also documented as CMagnitude — one description covers them all.

Description

Returns the magnitude of a complex number.

Example

DIM c AS _complex = (2, 3) PRINT CAbs(c) Output: 3.60555127546399
