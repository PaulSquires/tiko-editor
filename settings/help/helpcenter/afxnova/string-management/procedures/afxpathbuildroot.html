AfxPathBuildRootfunction

Creates a root path from a given drive number.

String ManagementfunctionAfxPath.incdocumented

Syntax

FUNCTION AfxPathBuildRoot (BYVAL nDrive AS LONG) AS DWSTRING

Parameters

NameDescription
nDriveA variable of type LONG that indicates the desired drive number. It should be between 0 and 25.

Return value

The root path. If the call fails for any reason (for example, an invalid drive number), an empty string is returned.

Description

Creates a root path from a given drive number.

Example

DIM dws AS DWSTRING = AfxPathBuildRoot(2) ' output: C:\
