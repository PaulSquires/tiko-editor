AfxPathMatchSpecExfunction

Searches a path to determine whether it contains a file of a specified file type extension.

String ManagementfunctionAfxPath.incdocumented

Syntax

FUNCTION AfxPathMatchSpecEx (BYREF wszFile AS CONST WSTRING, BYREF wszSpec AS CONST WSTRING, BYVAL dwFlags AS DWORD) AS BOOLEAN

Parameters

NameDescription
wszFileA string that contains the path to be searched.
wszSpecA string that contains the file type extension or extensions for which to search. If exactly one extension is specified, set the PMSF_NORMAL flag in dwFlags. If more than one extension is specified, separate them with semicolons and set the PMSF_MULTIPLE flag.
dwFlagsModifies the search condition. The following are valid flags:
PMSF_NORMAL (&h00000000): The wszSpec parameter points to a single file type extension to be matched.
PMSF_MULTIPLE (&h00000001): The wszSpec parameter points to a semicolon-delimited list of file type extensions to be matched.
PMSF_DONT_STRIP_SPACES (&h00010000): If PMSF_NORMAL is used, ignore leading spaces in the string pointed to by wszSpec. If PMSF_MULTIPLE is used, ignore leading spaces in each file type contained in the string pointed to by wszSpec. This flag can be combined with PMSF_NORMAL and PMSF_MULTIPLE.

Return value

Returns one of the following values:

Description

Searches a path to determine whether it contains a file of a specified file type extension.
