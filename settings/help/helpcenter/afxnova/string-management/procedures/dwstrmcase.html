DWStrMCasefunction

Returns a mixed case version of its string argument.

String ManagementfunctionDWSTRProcs.incdocumented

Syntax

FUNCTION DWStrMCase (BYREF wszSourceString AS WSTRING) AS DWSTRING

Description

Returns a mixed case version of its string argument.

Example

DIM dws AS DWSTRING = strMCase("Cats aren't AL.WAYS good.") ' Output: "Cats Aren'T Al.Ways Good." ' Note: It mimincs PowerBASIC's MCase$ function.
