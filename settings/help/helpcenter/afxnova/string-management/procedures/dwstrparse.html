DWStrParsefunction

Returns a delimited field from a string expression.

String ManagementfunctionDWSTRProcs.incdocumented

Syntax

FUNCTION DWStrParse (BYREF wszSourceString AS CONST WSTRING, BYVAL index AS LONG = 1, BYREF wszDelimiter AS CONST WSTRING = ",") AS DWSTRING

Parameters

NameDescription
wszSourceStringThe string to be parsed.
nPositionStarting position. If nPosition is zero or is outside of the actual field count, an empty string is returned. If nPosition is negative, fields are searched from the right to left of wszSourceString.
wszDelimiterA string of one or more characters that must be fully matched to be successful.

Description

Returns a delimited field from a string expression.

Example

DIM dws AS DWSTRING = DWStrParse("one,two,three") ' Output: "one" DIM dws AS DWSTRING = DWStrParse("one;two,three", 1, ";") ' Output: "one" DIM dws AS DWSTRING = DWStrParse("1;2,3", 2, ",;") ' Output: "2"
