DWStrSpnfunction

Returns the index of the initial portion of a string which consists only of characters that are part of a specified set of characters.

String ManagementfunctionDWSTRProcs.incdocumented

Syntax

FUNCTION DWStrSpn (BYREF wszText AS CONST WSTRING, BYREF wszSet AS CONST WSTRING, BYVAL IgnoreCase AS LONG = TRUE) AS LONG

Parameters

NameDescription
wszTextThe string to be scanned.
wszSetThe set of characters for which to search.
IgnoreCaseBoolean. If False, the search is case-sensitive; otherwise, it is case-insensitive.

Description

Returns the index of the initial portion of a string which consists only of characters that are part of a specified set of characters.

Remarks

The Windows API StrSpnW function and the C wcsspn function can also be used.

Example

DIM dwsText AS DWSTRING = "129th" DIM dwsSet AS DWSTRING = "1234567890" DIM n AS LONG = DWStrSpn(dwsText, dwsSet) PRINT "The initial number has " & WSTR(n) & " digits" ' Output: "3"
