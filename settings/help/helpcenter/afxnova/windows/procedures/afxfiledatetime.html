AfxFileDateTimefunction

Returns the file's last modified date and time as Date Serial.

WindowsfunctionAfxWin.incdocumented

Syntax

FUNCTION AfxFileDateTime (BYREF wszFileName AS WSTRING) AS DOUBLE

Return value

The date and time as a Date Serial. If it fails, it returns 0.

Description

Returns the file's last modified date and time as Date Serial. Unicode replacement for Free Basic's FileDateTime.

Example

#include "windows.bi" #include "vbcompat.bi" #include "Afx/AfxWin.bi" DIM wszFileName AS WSTRING * MAX_PATH = ExePath & "\c2.bas" DIM dt AS DOUBLE = AfxFileDateTime(wszFileName) PRINT Format(dt, "yyyy-mm-dd hh:mm AM/PM")
