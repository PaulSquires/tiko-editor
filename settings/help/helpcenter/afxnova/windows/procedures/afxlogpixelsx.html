AfxLogPixelsXfunction

Retrieves the number of pixels per logical inch along the screen width.

WindowsfunctionAfxWin.incdocumented

Syntax

FUNCTION AfxLogPixelsX () AS LONG
Also documented as AfxGetDpi, AfxGetDpiX — one description covers them all.

Description

Retrieves the number of pixels per logical inch along the screen width. In a system with multiple display monitors, this value is the same for all monitors. Aliases: AfxGetDpi, AfxGetDpiX.
