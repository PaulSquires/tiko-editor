AfxSaveIconToFilefunction

Saves an icon to a file.

WindowsfunctionAfxWin.incdoc-orphan

Syntax

FUNCTION AfxSaveIconToFile (BYVAL hIcon AS HICON, BYREF fileName AS WSTRING) AS HRESULT

Parameters

NameDescription
hIconThe icon handle.
fileNameThe name of the file to save.

Return value

Returns S_OK on success or and HRESULT code on failure.

Description

Saves an icon to a file.

Examples

DIM hIcon as HICON = LoadIcon(NULL, IDI_INFORMATION) DIM hr AS HRESULT = AfxSaveIconToFile(hIcon, "test.ico")

DIM hIcon AS HICON = cast(HICON, LoadImage(NULL, ExePath & "\" & "MyIco.ico", IMAGE_ICON, 32, 32, LR_LOADFROMFILE)) DIM hr AS HRESULT = AfxSaveIconToFile(hIcon, "test2.ico")
