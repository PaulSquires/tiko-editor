CEdit.GetRectmethod

Gets the formatting rectangle of an edit control.

WindowsmethodCEdit.incdocumented

Syntax

SUB CEdit.GetRect (BYVAL hEdit AS HWND, BYVAL prc AS RECT PTR)
SUB GetRect (BYVAL hEdit AS HWND, BYREF rc AS RECT)
FUNCTION GetRect (NYVAL hEdit AS HWND) AS RECT

Parameters

NameDescription
prcA pointer to a RECT structure that receives the formatting rectangle.
rcA RECT structure that receives the formatting rectangle.

Return value

Gets the formatting rectangle of an edit control. The formatting rectangle is the limiting rectangle into which the control draws the text. The limiting rectangle is independent of the size of the edit-control window.

Description

Gets the formatting rectangle of an edit control. The formatting rectangle is the limiting rectangle into which the control draws the text. The limiting rectangle is independent of the size of the edit-control window.

Example

DIM rc AS RECT CEdit.GetRect(hEdit, @rc) CEdit.GetRect(hEdit, rc) rc = CEdit.GetRect(hEdit)
