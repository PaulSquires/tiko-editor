CEdit.SetModifymethod

Sets or clears the modification flag for an edit control.

WindowsmethodCEdit.incdocumented

Syntax

SUB SetModify (BYVAL hEdit AS HWND, BYVAL bModify AS BOOLEAN)

Parameters

NameDescription
hEditThe handle of the edit control.
bModifyThe new value for the modification flag. A value of TRUE indicates the text has been modified, and a value of FALSE indicates it has not been modified.

Description

Sets or clears the modification flag for an edit control. The modification flag indicates whether the text within the edit control has been modified.

Example

CEdit.SetModify(hEdit, TRUE)
