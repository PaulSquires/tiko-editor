CHeader.SetHotDividermethod

Changes the color of a divider between header items to indicate the destination of an external drag-and-drop operation.

WindowsmethodCHeader.incdocumented

Syntax

FUNCTION SetHotDivider (BYVAL hHeader AS HWND, BYVAL fPos AS BOOLEAN, BYVAL dwInputValue AS LONG) AS LONG

Parameters

NameDescription
hHeaderThe handle of the header control.
fPosA value specifying how dw is to be interpreted. The value in this field can be one of the following:
TRUE: Indicates that dw holds client coordinates of the pointer.
FALSE: Indicates that dw holds a divider index value.
dwInputValueThe value held here is interpreted depending on the value of fPos. If fPos is TRUE, dw represents the x- and y- client coordinates of the pointer. The x-coordinate is in the low word, and the y-coordinate is in the high word. Upon receiving the message, the header control highlights the appropriate divider based on the dw coordinates. If fPos is FALSE, dwInputValue represents the integer index of the divider that will be highlighted.

Return value

Returns the index of the divider that the control highlighted.

Description

Changes the color of a divider between header items to indicate the destination of an external drag-and-drop operation.

Remarks

A header control set to the HDS_DRAGDROP style produces this effect automatically. This message is intended to be used when the owner of the control handles drag-and-drop operations manually.
