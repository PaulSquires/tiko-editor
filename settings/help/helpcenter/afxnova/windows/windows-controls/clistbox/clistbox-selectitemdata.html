CListBox.SelectItemDatamethod

Searches a list box for an item that has the specified item data.

WindowsmethodCListBox.incdocumented

Syntax

SUB SelectItemData (BYVAL hListBox AS HWND, BYVAL indexStart AS LONG, BYVAL pData AS ANY PTR) AS LONG

Parameters

NameDescription
hListBoxThe handle of the listbox control.
indexStartThe zero-based index of the item before the first item to be searched. When the search reaches the bottom of the list box, it continues searching from the top of the list box back to the item specified by the indexStart parameter. If indexStart is -1, the entire list box is searched from the beginning.
pDataThe data value to find.

Description

Searches a list box for an item that has the specified item data. If a matching item is found, the item is selected.

Example

CListBox.SelectItemData(hListBox, 3, pData)
