CProgBar.SetBarColormethod

Sets the color of the progress indicator bar in the progress bar control.

WindowsmethodCProgBar.incdocumented

Syntax

FUNCTION SetBarColor (BYVAL hProgBar AS HWND, BYVAL clrBar AS COLORREF) AS COLORREF

Parameters

NameDescription
hProgBarA handle to a progress bar.
clrBarThe COLORREF value that specifies the new progress indicator bar color. Specifying the CLR_DEFAULT value causes the progress bar to use its default progress indicator bar color.

Return value

Returns the previous progress indicator bar color, or CLR_DEFAULT if the progress indicator bar color is the default color.

Description

Sets the color of the progress indicator bar in the progress bar control.

Remarks

When visual styles are enabled, this message has no effect.
