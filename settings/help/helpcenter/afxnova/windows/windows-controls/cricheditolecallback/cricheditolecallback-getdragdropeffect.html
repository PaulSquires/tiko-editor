CRichEditOleCallback.GetDragDropEffectmethod

Allows the client to specify the effects of a drop operation.

Windowsmethoddocumented

Syntax

FUNCTION GetDragDropEffect (BYVAL fDrag AS WINBOOL, BYVAL grfKeyState AS DWORD, BYVAL pdwEffect AS LPDWORD) AS HRESULT

Parameters

NameDescription
fDragTRUE if the query is for a IDropTarget.DragEnter or IDropTarget.DragOver. FALSE if the query is for IDropTarget.Drop.
grfKeyStateKey state as defined by OLE.
pdwEffectThe effect used by a rich edit control. When fDrag is TRUE, on return, its content is set to the effect allowable by the rich edit control. When fDrag is FALSE, on return, the variable is set to the effect to use.

Return value

This method returns S_OK.

Description

Allows the client to specify the effects of a drop operation.
