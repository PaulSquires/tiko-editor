CTab.GetImageIndexmethod

Gets the 0-based index in the tab control's image list.

WindowsmethodCTab.incdocumented

Syntax

FUNCTION GetImageIndex (BYVAL hTab AS HWND, BYVAL iItem AS DWORD) AS LONG

Parameters

NameDescription
hTabHandle to the tab control.
iItemZero-based index of the tab.

Return value

Returns the index of the image or -1 if not found.

Description

Gets the 0-based index of an image in the tab control's image list.

Example

DIM idx AS LONG = CTab.GetImageIndex(hTab, 1)
