CTextFont2.ForeColormethod

Gets/sts the foreground, or text, color.

Windowsmethoddocumented

Syntax

PRIVATE PROPERTY CTextFont2.ForeColor () AS LONG

Parameters

NameDescription
ValueThe new foreground color. It can be one of the following.

Return value

The foreground color. It can be one of the ones listed above.

Description

Gets/sets the foreground, or text, color.

If Value contains an RGB color, generate the COLORREF by using the RGB macro (BGR function in FreeBasic).

Example

(GET) PROPERTY ForeColor () AS LONG (SET) PROPERTY ForeColor (BYVAL Value AS LONG)
