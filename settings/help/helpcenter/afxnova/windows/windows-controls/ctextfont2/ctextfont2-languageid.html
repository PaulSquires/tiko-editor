CTextFont2.LanguageIDproperty

Gets/sets the language ID or language code identifier (LCID).

Windowspropertydocumented

Syntax

PRIVATE PROPERTY CTextFont2.LanguageID () AS LONG

Parameters

NameDescription
ValueThe new value of the minimum kerning size, in floating-point points.

Return value

The language ID or LCID. The low word contains the language identifier. The high word is either zero or it contains the high word of the LCID. To retrieve the language identifier, mask out the high word. For more information, see Locale Identifiers.

Description

Gets/sets the language ID or language code identifier (LCID).

The new language identifier. The low word contains the language identifier. The high word is either zero or it contains the high word of the locale identifier LCID. For more information, see Locale Identifiers.

Remarks

If the high nibble of Value is tomCharset, set the charrep from the charset in the low byte and the pitch and family from the next byte. See also SetCharRep.

If the high nibble of Value is tomCharRepFromLcid, set the charrep from the LCID and set the LCID as well. See GetLanguageID for more information.

To set the BCP-47 language tag, such as "en-US", call SetText2 and set the tomLanguageTag and bstr with the language tag.
