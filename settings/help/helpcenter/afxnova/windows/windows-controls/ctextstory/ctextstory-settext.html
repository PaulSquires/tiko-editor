CTextStory.SetTextmethod

Sets the text in this range.

Windowsmethoddocumented

Syntax

FUNCTION SetText (BYVAL Flags AS LONG, BYREF wszText AS WstRING) AS HRESULT

Parameters

NameDescription
FlagsFlags controlling how the text is inserted as defined in the following table: tomCheckTextLimit, tomMathCFCheck, tomUnhide, tomUnicodeBiDi, tomUnlink.
wszTextThe new text for this story. If this parameter is "", the text in the story is deleted.

Return value

If the method succeeds, GetLastResult returns S_OK. If the method fails, it returns one of the following COM error codes.

Description

Replaces the text in a story with the specified text.
