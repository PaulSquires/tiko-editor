RichEdit_SetFontfunction

Sets the font used by a rich edit control.

Windowsfunctiondocumented

Syntax

FUNCTION RichEdit_SetFont (BYVAL hRichEdit AS HWND, BYREF wszFaceName AS WSTRING, BYVAL ptsize AS LONG) AS LRESULT

Parameters

NameDescription
hRichEditThe handle of the rich edit control.
wszFaceNameThe font name.
ptsizeThe font size in points.

Return value

If the operation succeeds, the return value is a nonzero value.

If the operation fails, the return value is zero.

Description

Sets the font used by a rich edit control.
