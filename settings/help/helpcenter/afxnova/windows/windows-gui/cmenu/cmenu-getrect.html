Parameters

NameDescription
hwnd= Handle of the window that owns the menu.
hmenu= Handle of the menu.
prcmenu= Pointer to a variable of type RECT where to return the retrieved values.

Return value

If the function succeeds, the return value is 0. If the function fails, the return value is a system error code. Usage example: DIM rc AS RECT = CMenu.GetRect(hWin, hMenu) print rc.left, rc.top, rc.right, rc.bottom

Calculates the size of a menu bar or a drop-down menu.
