Retrieves the state of the specified menu item.

Syntax

PRIVATE FUNCTION CMenu.GetState (BYVAL hMenu AS HMENU, BYVAL item AS LONG, BYVAL fByPosition AS BOOLEAN = FALSE) AS UINT

Parameters

NameDescription
hMenu= A handle to the menu that contains the menu item.
item= The identifier or position of the menu item to get information about. The meaning of this parameter depends on the value of fByPosition.
fByPosition= The meaning of item. If this parameter is FALSE, item is a menu item identifier. Otherwise, it is a menu item position.
MFS_CHECKEDThe item is checked
MFS_DEFAULTThe menu item is the default.
MFS_DISABLEDThe item is disabled.
MFS_ENABLEDThe item is enabled.
MFS_GRAYEDThe item is grayed.
MFS_HILITEThe item is highlighted
MFS_UNCHECKEDThe item is unchecked.
MFS_UNHILITEThe item is not highlighted. Note: To get extended error information, use the GetLastError function. Usage example: CMenu.GetState(hMenu, IDM_OPEN)

Return value

0 on failure or one or more of the following values:

Description

Retrieves the state of the specified menu item.
