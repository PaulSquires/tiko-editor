CWindow.CreateAcceleratorTablemethod

Creates the accelerator table.

WindowsmethodCWindow.incdocumented

Syntax

FUNCTION CreateAcceleratorTable () AS HACCEL

Return value

The handle of the new accelerator table.

Description

Creates the accelerator table.

Example

' // Create a keyboard accelerator table pWindow.AddAccelerator FVIRTKEY OR FCONTROL, "U", IDM_UNDO ' // Ctrl+U - Undo pWindow.AddAccelerator FVIRTKEY OR FCONTROL, "R", IDM_REDO ' // Ctrl+R - Redo pWindow.AddAccelerator FVIRTKEY OR FCONTROL, "H", IDM_HOME ' // Ctrl+H - Home pWindow.AddAccelerator FVIRTKEY OR FCONTROL, "S", IDM_SAVE ' // Ctrl+S - Save DIM hAccel AS HACCEL = pWindow.CreateAcceleratorTable
