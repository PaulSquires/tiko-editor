MenuGetStatefunction

Retrieves the state of the specified menu item.

Windowsfunctiondocumented

Syntax

FUNCTION MenuGetState (BYVAL hMenu AS HMENU, BYVAL item AS LONG, BYVAL fByPosition AS BOOLEAN = FALSE) AS UINT

Parameters

NameDescription
hMenuA handle to the menu that contains the menu item.
itemThe identifier or position of the menu item to get information about. The meaning of this parameter depends on the value of fByPosition.
fByPositionThe meaning of item. If this parameter is FALSE, item is a menu item identifier. Otherwise, it is a menu item position, where position = 1 for the first position, position = 2 for the second, and so on.

Return value

0 on failure or one or more of the following values:

Description

Retrieves the state of the specified menu item.
