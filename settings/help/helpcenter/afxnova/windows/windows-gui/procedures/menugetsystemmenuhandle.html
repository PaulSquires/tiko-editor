MenuGetSystemMenuHandlefunction

Enables the application to access the window menu (also known as the system menu or the control menu) for copying and modifying.

Windowsfunctiondocumented

Syntax

FUNCTION MenuGetSystemMenuHandle (BYVAL hwnd AS HWND, BYVAL bRevert AS BOOLEAN = FALSE) AS HMENU
Also documented as MenuGetTextLen — one description covers them all.

Parameters

NameDescription
hMenuA handle to the menu.
itemThe identifier or position of the menu item to get information about. The meaning of this parameter depends on the value of fByPosition.
fByPositionThe meaning of item. If this parameter is FALSE, item is a menu item identifier. Otherwise, it is a menu item position, where position = 1 for the first position, position = 2 for the second, and so on.
hMenuA handle to the menu.
hMenuA handle to the menu.
hMenuA handle to the menu.
bRevertThe action to be taken. If this parameter is FALSE, MenuGetSystemMenuHandle returns a handle to the copy of the window menu currently in use. The copy is initially identical to the window menu, but it can be modified. If this parameter is TRUE, MenuGetSystemMenuHandle resets the window menu back to the default state. The previous window menu, if any, is destroyed.

Return value

The length of the text.

The handle of the window that owns the menu.

The handle of the window that owns the menu.

If the bRevert parameter is FALSE, the return value is a handle to a copy of the window menu. If the bRevert parameter is TRUE, the return value is NULL.

Description

Returns the lengnth of the text of the specified menu item.
