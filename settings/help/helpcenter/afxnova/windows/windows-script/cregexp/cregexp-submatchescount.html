CRegExp.SubMatchesCountproperty

Returns the number of submatches.

WindowspropertyCRegExp.incdocumented

Syntax

PROPERTY SubMatchesCount (BYVAL index AS LONG = 0) AS LONG

Parameters

NameDescription
index0-based index of the match to retrieve.

Description

Returns the number of submatches.
