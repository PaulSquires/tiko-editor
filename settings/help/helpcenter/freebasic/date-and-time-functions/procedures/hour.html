Hourfunction

Gets the hour of day from a Date Serial

Date and Time Functionsfunctiondocumented

Syntax

Declare Function Hour ( ByVal date_serial As Double ) As Long

Parameters

NameDescription
date_serialthe date serial

Return value


Returns the hour from a variable containing a date in Date Serial format.

Description


The compiler will not recognize this function unless vbcompat.bi is included.

Remarks

Usage


#include "vbcompat.bi"
result = Hour( dateserial )

Differences from QB


  • Did not exist in QB. This function appeared in PDS and VBDOS

See also


  • Date Serials

Example


#include "vbcompat.bi"



Dim ds As Double = DateSerial(2005, 11, 28) + TimeSerial(7, 30, 50)



Print Format(ds, "yyyy/mm/dd hh:mm:ss "); Hour(ds)
