__FB_UNIX__keyword

Intrinsic define set by the compiler

Intrinsic Defineskeyworddocumented

Syntax

__FB_UNIX__

Description


Define created at compile time if the OS is reasonably enough like UNIX that you can call it UNIX, otherwise undefined.

Remarks

Differences from QB


  • New to FreeBASIC

See also


  • __FB_LINUX__
  • __FB_FREEBSD__
  • __FB_OPENBSD__
  • __FB_NETBSD__
  • __FB_CYGWIN__
  • __FB_DARWIN__
  • __FB_PCOS__
  • Compiler Option: -target

Example


#ifdef __FB_UNIX__

  '...instructions for UNIX-family OSes...

#else

  '...instructions for other OSes

#endif
