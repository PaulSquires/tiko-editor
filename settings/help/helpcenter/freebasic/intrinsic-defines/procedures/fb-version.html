__FB_VERSION__keyword

Intrinsic define (macro string) set by the compiler

Intrinsic Defineskeyworddocumented

Syntax

__FB_VERSION__

Description


Substituted by the version number of the compiler where used.

Remarks

Differences from QB


  • Did not exist in QB

See also


  • __FB_SIGNATURE__
  • __FB_WIN32__
  • __FB_LINUX__
  • __FB_DOS__


Example


#if __FB_VERSION__ < "0.18" 

#error  Please compile With FB version 0.18 Or above 

#endif

This will stop the compilation if the compiler version is below 0.18
