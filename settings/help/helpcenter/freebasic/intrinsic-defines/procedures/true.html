Truekeyword

Intrinsic constant set by the compiler

Intrinsic Defineskeyworddocumented

Syntax

Const True As Boolean

Description


Gives the True Boolean value where used.

Remarks

Version


  • Since fbc 1.04.0

Dialect Differences


  • Not available in the -lang qb dialect unless referenced with the alias __True.

Differences from QB


  • New to FreeBASIC

See also


  • False
  • Boolean

Example


Dim b As Boolean = True

If b Then

    Print "b is True"

Else

    Print "b is False"

End If


b is True

Reference

  • Documented in KeyPgTrue.html
