FreeBASIC

Documentation

FreeBASIC is an open source (under GPL) compiler. It is designed to be syntax compatible with QuickBASIC, while expanding on the language and capabilities. It compiles for DOS, Microsoft Windows and Linux, and is being ported to other platforms.
