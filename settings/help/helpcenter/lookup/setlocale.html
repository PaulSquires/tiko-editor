SetLocale

3 symbols share this name. Pick the one you meant.

CCombo.SetLocaleSets the current locale of the combo box. If the combo box has the CBS_SORT style and strings are added using CB_ADDSTRING, the locale of a combo box affects how list items are sorted. The return value is the previous locale identifier. If lcid specifies a locale not installed on the system, the return value is CB_ERR and the current combo box locale is not changed.CComboEx.SetLocaleSets the current locale of the combo box.CListBox.SetLocaleSets the current locale of the list box.
