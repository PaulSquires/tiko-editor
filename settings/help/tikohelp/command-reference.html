Note

Commands are listed by category, matching the grouping in the Keyboard Shortcuts dialog.

Using command identifiers

A line in keybindings.ini is a command identifier, a colon, and the keystroke:

iniBinding commands by identifier
IDM_DUPLICATELINE:Ctrl+Shift+D
IDM_FORMATSELECTION:Ctrl+Alt+F
IDM_BOOKMARKNEXT(DISABLED):

A (DISABLED) marker suppresses that command's default shortcut without assigning a new one.

Warning

An identifier Tiko does not recognise is ignored, and the command keeps its default. Nothing reports the mistake, so check your spelling against the tables above.
