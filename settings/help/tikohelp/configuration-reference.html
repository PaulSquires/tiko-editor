Configuration reference

Every setting in settings.ini: what it does, its default, the values it accepts and the settings it relates to.

Every setting Tiko Editor stores in settings\settings.ini. Most are set through File›Settings›Options…; they are documented here so you can read the file, compare two installations, or edit it in bulk.

Important

Booleans follow the BASIC convention: -1 means true and 0 means false.

Warning

Close Tiko Editor before editing the file by hand. It rewrites the whole file on exit, which discards anything you changed while it was running.

Note

Compiler paths are stored with a {CURDRIVE} token in place of the drive letter, so an installation keeps working when the same folder is opened from a different drive — a USB stick that mounts as E: on one machine and F: on another.

[Startup] — window and layout

These are maintained by Tiko Editor as you move and resize things. They are listed for completeness; edit them only to move a window that has ended up off screen — View›Restore Main Window Size does the same thing more safely.

KeyHolds
StartupLeft, StartupTop, StartupRight, StartupBottomThe main window's position and size.
StartupMaximizedWhether the main window was maximised.
HelpStartupLeft … HelpStartupMaximizedThe same for the Help Center window.
ShowPanelWhether the side panel is visible.
ShowPanelWidthThe side panel's width in pixels.
ShowOutputPanelWhether the Output panel is visible.
ShowOutputPanelHeightThe Output panel's height in pixels.
ShowOutputPanelMinimizedWhether the Output panel is collapsed to its tab strip.
ShowOutputPanelIndexWhich Output panel tab was active.
UnusedKindMaskWhich symbol kinds the Unused Symbols report includes — a bitmask over the six kinds, in order: variables (1), procedures (2), parameters (4), types (8), fields (16), constants (32). The default 63 is all six.
NoteShowOutputPanel and ShowOutputPanelMinimized are separate on purpose. All four combinations are meaningful — including closed, but reopens minimised.
