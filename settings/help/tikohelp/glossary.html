Glossary

Plain-language definitions of the editing, project, build and debugging terms used across this documentation.

Terms used throughout this documentation, in alphabetical order.

Accelerator
A keyboard shortcut that runs a command directly, such as Ctrl + S. See Keyboard shortcuts.
ANSI
The legacy single-byte Windows encoding for a locale. Adequate for plain ASCII, unreliable for anything else. See Encoding.
Autocomplete
A list of possible completions offered as you type an identifier. See Autocomplete and code tips.
BOM (byte-order mark)
A few bytes at the start of a file recording its encoding. Some tools require one; others cannot cope with it.
Bookmark
A marked line you can jump back to. Stored in the editor, not in the file. See Bookmarks.
Breakpoint
A marker telling the debugger to stop your program when execution reaches that line. See Breakpoints.
Build configuration
A named set of compiler switches, such as Debug or Release. See Build configurations.
Call stack
The chain of procedure calls that reached the current line, innermost first. See Watches and the call stack.
Caret
The blinking text insertion point. Distinct from the mouse cursor.
Code tip
A popup showing a procedure's parameters, displayed when you open its call parenthesis. Sometimes called a call tip.
Column selection
A rectangular selection covering the same columns on several lines. See Multiple selections and column mode.
Compiler
The program that turns source code into an executable. Tiko drives the FreeBASIC compiler; it does not include one.
CRLF / LF / CR
The three line-ending conventions: Windows, Unix and classic Mac OS. See Encoding and line endings.
Data tip
The value of a variable shown when you hover over it in the editor while debugging.
Encoding
The rule mapping bytes in a file to characters — UTF-8, ANSI and so on.
Fold
A collapsed block of code, shown as a single line. Folding is a display state and does not change the file. See Code folding.
FreeBASIC
The BASIC-dialect compiler Tiko is built around. Free, open source and self-hosting.
Gutter / margin
The narrow strips left of the text holding line numbers, bookmark and breakpoint markers, and fold markers.
Help Center
Tiko's built-in documentation browser, opened with F1.
Keyword
A word with special meaning in a language, such as Dim or Function. Keyword lists live in settings\keywords.
Lexer
The component that breaks source into tokens so it can be coloured. Tiko uses Lexilla. See Syntax highlighting.
Localization
Presenting the interface in another language, from a .lang file. See Localization.
Main module
The file in a project holding the program's entry point.
Monospaced font
A font in which every character is the same width. Required for code alignment to work.
Multiple selections
Several independent selections or carets edited at once.
Parser
The component that reads your source and extracts its symbols. Tiko's runs in the background and powers Goto Definition, autocomplete and the function list.
Project
A named workspace: a set of files plus its options, stored in a .tiko file. See Projects and workspaces.
Regular expression
A pattern language for describing sets of strings, offered by some editors for advanced searching. Tiko does not support them — its searches are literal text, refined by Match Case, Match Whole Words and Selection.
Resource script
A .rc file describing icons, menus, dialogs and version information compiled into a Windows program.
Scintilla
The open-source editing component Tiko's editing surface is built on, also used by Notepad++ and SciTE.
Side panel
The dock beside the editor hosting the Explorer, function list and bookmarks. Toggle with Ctrl + B.
Splitter
A draggable bar between two regions of the window.
Step into / over / out
The three ways of advancing a stopped program: entering calls, running them to completion, or running until the current procedure returns.
Symbol
A named thing in your code — a procedure, type, enumeration or variable — that the parser has indexed.
Syntax highlighting
Colouring code according to what each part of it means.
TODO comment
A comment marking work still to be done. Tiko collects them into the Output panel's TODO tab.
Token
The smallest meaningful unit of source — an identifier, keyword, operator or literal. The formatter compares tokens to prove it preserved your code.
Unicode
The standard assigning a number to every character in every writing system. UTF-8 and UTF-16 are ways of storing those numbers as bytes.
User tool
An external program you can run from Tiko's menu. See User tools.
UTF-8
The dominant Unicode encoding. Byte-compatible with ASCII for plain English text, and able to represent every Unicode character.
Watch
An expression the debugger re-evaluates every time your program stops.
Whole word
A search option requiring a match to be a complete word rather than part of a longer one.
Workspace
The set of files currently open, which in Tiko is always a project — named or untitled.
Zoom
A temporary change to displayed text size. It does not alter the configured font size.
