Customizing keyboard shortcuts

Rebinding any command, resolving conflicts, disabling a default, and where your bindings are stored.

Every command in Tiko can be rebound. Open the Keyboard Shortcuts dialog with File›Settings›Keyboard Shortcuts… or Ctrl + K.

The dialog

The dialog lists every command with four columns — the category, the command, its current shortcut and its description — above a filter box that searches all four. Type part of a command name or a key name to narrow the list.

ButtonWhat it does
ModifyOpens the assignment dialog for the selected command.
ResetRestores the selected command to its default shortcut.
OKSaves every change and rebuilds the accelerator table.
CancelDiscards every change. Nothing you did in the dialog takes effect.
Note

The dialog works on a copy of your bindings, so Cancel really cancels — you can experiment freely and back out.

Assigning a shortcut

  1. Select the command and choose Modify.
  2. Either press the keystroke you want in the capture field, or build it by hand: toggle the Ctrl, Alt and Shift switches and pick the key from the list.
  3. If the keystroke is already taken, the dialog says so and refuses it rather than silently stealing it from the other command.
  4. Choose OK in the assignment dialog, then OK in the main dialog to commit.

Conflicts

A keystroke can only do one thing. Tiko checks for conflicts across editor commands, user tools and build configuration shortcuts, and marks any conflict it finds in the list.

Where a conflict is inherited from an older settings file, the first command to claim the keystroke keeps it and the others show as unassigned. Reassign the loser to something free.

Disabling a default

A default shortcut can be suppressed without being replaced — useful when a keystroke conflicts with something outside Tiko, such as a global hotkey from another application. A suppressed default shows in the list marked as disabled.

Where bindings are stored

Your changes go into settings\keybindings.ini. Only your overrides are stored — the defaults live in the program, so the file stays small and readable:

inisettings\keybindings.ini
IDM_FILESAVE:Ctrl+S
IDM_DUPLICATELINE:Ctrl+Shift+D
IDM_BOOKMARKTOGGLE(DISABLED):

Each line names a command, then the keystroke you assigned. A (DISABLED) marker after the command name means its default is suppressed. Deleting the file restores every default.

Tip

Copy keybindings.ini to another machine to take your shortcuts with you. See Settings and configuration files.
