Keyboard shortcuts

Every default keyboard shortcut in Tiko Editor, grouped by category and ready to print.

Every shortcut below is the factory default. All of them can be changed — see Customizing keyboard shortcuts. A command shown with a dash has no default shortcut, and is a good candidate if you need a free keystroke.

Tip

This page prints cleanly. Use your browser's Print command for a reference sheet without the navigation.

The ten to learn first

If you learn nothing else, learn these. They cover the great majority of daily use.

ShortcutCommandWhy
Ctrl + SSaveConstantly.
Ctrl + FFindThe most-used navigation tool in any editor.
F3Find NextRepeats the search without the Find bar open.
F12Goto DefinitionJump to where anything is defined.
Alt + LeftGo BackReturn from that jump.
Ctrl + PSearch SymbolJump anywhere in the project by name.
F5Build And ExecuteThe whole build cycle in one key.
F9Toggle BreakpointThe start of every debugging session.
F6Start DebuggingRun under the debugger.
Ctrl + BToggle side panelGive the editor the whole window.

File commands

Creating, opening, saving and closing documents, plus the settings dialogs.

ShortcutCommandDescription
Ctrl + NNewCreate a new, empty document.
Ctrl + OOpen…Open one or more existing files.
—Open File As Template…Open a file's contents as a new untitled document, leaving the original untouched.
Ctrl + WCloseClose the active document. It stays in the project.
Ctrl + Shift + WClose AllClose every open document.
Ctrl + SSaveSave the active document. Prompts for a name if it has never been saved.
—Save As…Save under a new name and continue editing the new file.
Ctrl + Shift + SSave AllSave every modified document.
—Rename…Rename the file on disk and update the project.
—DuplicateCreate a copy of the file and add it to the project.
Ctrl + ,Options…Open the main options dialog.
Ctrl + Shift + TThemes…Choose and edit colour themes.
Ctrl + KKeyboard Shortcuts…Remap any command.
F7Build Configurations…Manage named sets of compiler switches.
—User Tools…Define external programs to run from the menu.
Alt + F4ExitClose Tiko Editor, prompting to save modified documents.

Edit commands

Undo and redo, the clipboard, line operations, commenting, case conversion and the code formatter.

ShortcutCommandDescription
Ctrl + ZUndoUndo the last change.
Ctrl + Shift + ZRedoReapply an undone change.
Ctrl + XCutCut the selection, or the whole line if nothing is selected.
Ctrl + CCopyCopy the selection, or the whole line if nothing is selected.
Ctrl + VPastePaste the clipboard as plain text.
Ctrl + YDelete LineDelete the current line.
Ctrl + DDuplicate LineInsert a copy of the current line below it.
Alt + UpMove Line UpSwap the current line or selection with the line above.
Alt + DownMove Line DownSwap the current line or selection with the line below.
Ctrl + /Comment BlockComment out the selected lines.
Ctrl + Shift + /UnComment BlockRemove comment marks from the selected lines.
Ctrl + LSelect LineSelect the whole current line.
Ctrl + ASelect AllSelect the entire document.
TabIndent BlockIndent every line of a multi-line selection.
Shift + TabUnIndent BlockRemove one indent level from every selected line.
Ctrl + IInsert FileInsert another file's contents at the caret.
Ctrl + Alt + UUppercaseConvert the selection to upper case.
Ctrl + Alt + LLowercaseConvert the selection to lower case.
Ctrl + Alt + XMixed caseConvert the selection to mixed case.
Ctrl + EnterNew Line BelowOpen a new line below the current one from anywhere on it.
Ctrl + `Focus EditorReturn keyboard focus to the editing window.
Shift + Alt + FFormat DocumentReformat the whole active file.
—Format SelectionReformat only the selected lines.
—Format All Open DocumentsReformat every open document.
—Format Project…Reformat every file in the workspace.
—Format Options…Configure the formatter, with a live preview.

Search commands

Finding text, navigating to symbols and definitions, and bookmarks.

ShortcutCommandDescription
Ctrl + PSearch Symbol…Filter every symbol in the project and jump to one.
Ctrl + FFind…Search within the active document.
F3Find NextRepeat the last search forwards.
Shift + F3Find PreviousRepeat the last search backwards.
Ctrl + Shift + FFind in Project…Search every file in the workspace.
Ctrl + HReplace…Find and replace within the active document.
F12Goto DefinitionJump to where the symbol under the caret is defined.
Alt + LeftGo BackReturn to the previous position in the navigation history.
Alt + RightGo ForwardMove forward again in the navigation history.
Ctrl + PgDnNext FunctionJump to the next procedure in the file.
Ctrl + PgUpPrevious FunctionJump to the previous procedure.
Ctrl + F2Toggle BookmarkSet or clear a bookmark on the current line.
F2Next BookmarkJump to the next bookmark.
Shift + F2Previous BookmarkJump to the previous bookmark.
Ctrl + Shift + F2Clear BookmarksRemove every bookmark.
Ctrl + Shift + HGoto Header FileSwitch to the matching header file.
Ctrl + Shift + CGoto Code FileSwitch to the matching source file.
Ctrl + Shift + MGoto Main FileSwitch to the project's main module.
Ctrl + Shift + RGoto Resource FileSwitch to the project's resource script.
Ctrl + TabNext TabActivate the next open document.
Ctrl + Shift + TabPrevious TabActivate the previous open document.

ShortcutCommandDescription

Ctrl + F4View Explorer WindowShow the project Explorer.
Ctrl + F9View Output WindowShow or hide the Output panel.
F4View Function ListShow the function list for the active document.
Shift + F4View Bookmarks ListShow every bookmark in the side panel.
Ctrl + + Zoom InIncrease the displayed text size.
Ctrl + -Zoom OutDecrease the displayed text size.
Ctrl + 0Zoom ResetReturn to the configured font size.
Ctrl + \Toggle Split Editor Left/RightSplit the editor into two side-by-side views of the same file.
Ctrl + Shift + \Toggle Split Editor Top/BottomSplit the editor horizontally.
F8Toggle Current Fold PointCollapse or expand the block at the caret.
Ctrl + F8Toggle Current And All BelowFold the current block and everything in it.
Shift + F8Fold AllCollapse every block in the document.
Ctrl + Shift + F8Unfold AllExpand every block.
—Move Explorer WindowDock the side panel on the other side.
—Restore Main Window SizeReturn the main window to its default size.
—NotesShow the workspace notes tab.
—TODOShow the collected TODO comments.
—Explorer: Expand AllExpand every node in the Explorer.
—Explorer: Collapse AllCollapse every node in the Explorer.
—Functions: Expand AllExpand every node in the function list.
—Functions: Collapse AllCollapse every node in the function list.
—Bookmarks: Expand AllExpand every node in the bookmarks list.
—Bookmarks: Collapse AllCollapse every node in the bookmarks list.
—Close Side PanelClose the side panel.

Project commands

Creating, opening and saving projects, and managing their files.

ShortcutCommandDescription
—New Project…Close the workspace and start a fresh untitled one.
—Open Project…Open a saved project file.
—Close ProjectClose the workspace and its files.
—Save ProjectWrite the project file.
—Save Project As…Save the project under a new name — also how an untitled workspace is named.
Ctrl + F11Add Files to Project…Add existing files to the workspace.
—Project Options…Edit this project's options.

Compile commands

Building, rebuilding and running your program.

ShortcutCommandDescription
F5Build And ExecuteCompile, then run if the compile succeeded.
Ctrl + F5CompileCompile without running.
Ctrl + Alt + F5Rebuild AllRebuild everything from scratch.
Ctrl + F7Compile ModuleCompile only the current module.
Ctrl + Shift + F5Quick RunCompile and run the current file alone, ignoring the project.
Shift + F5Run ExecutableRun the last successful build without recompiling.
—Command Line…Show the compiler command line Tiko Editor will use.

Debug commands

Starting and controlling a debugging session, and breakpoints.

ShortcutCommandDescription
F6Start / Continue DebuggingStart a debugging session, or resume a stopped one.
Ctrl + F6BreakInterrupt the running program at the next source line.
Shift + F6Stop DebuggingEnd the session and terminate the program.
F11StepExecute one line, entering any procedure it calls.
F10Step OverExecute one line without stopping inside calls.
Shift + F11Step OutRun until the current procedure returns.
Ctrl + F10Run to CursorResume and stop at the line holding the caret.
F9Toggle BreakpointSet or clear a breakpoint on the current line.
Ctrl + Shift + F9Delete All BreakpointsRemove every breakpoint.
—Unused Symbols…Report declared symbols the parser found no use of.

Help commands

The Help Center and version information.

ShortcutCommandDescription
F1Help CenterOpen the Help Center, searching for the selection or the word under the caret.
—AboutShow version, credits and licence information.

Keys handled outside the command table

These are handled by the editing surface itself, or claimed before the accelerator tables, so they do not appear in the Keyboard Shortcuts dialog and cannot be remapped there.

ShortcutAction
Ctrl + SpaceRaise the word autocomplete list. The only keyboard trigger for it — see Autocomplete.
Home / EndStart / end of line.
Ctrl + Home / Ctrl + EndStart / end of document.
Ctrl + Left / Ctrl + RightPrevious / next word.
Shift + any movementExtend the selection.
Alt + dragRectangular (column) selection.
Alt + Shift + arrowsRectangular selection by keyboard.
Ctrl + drag, click or double-clickAdd another selection or caret (multi-cursor editing).
InsertToggle insert and overwrite mode.
Ctrl + mouse wheelZoom in and out.
Shift + mouse wheelScroll horizontally.

Notation

  • Ctrl+, is the comma key — written Comma in the shortcut dialog's key list.
  • Ctrl+` is the backtick or tilde key — written Tilde.
  • Ctrl++ and Ctrl+- are the plus and minus keys; the numeric keypad equivalents also work.
