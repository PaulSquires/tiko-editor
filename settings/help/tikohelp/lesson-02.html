Lesson 2 — Creating your first file

Create, type, save and reopen a file, and understand what Save As does.

Goal: Create, type, save and reopen a file, and understand what Save As does.Time: 10 minutesBefore you start: Lesson 1.

What you will learn

  • Creating a document and saving it for the first time.
  • The difference between Save and Save As.
  • Closing a document and reopening it from Open Recent.
  • Why your files come back when you restart Tiko.

Create a file

  1. Press Ctrl + N. A tab appears, named Untitled.
  2. Type the program below. Watch the keywords colour themselves as you type.
fbgreet.bas
' greet.bas - Lesson 2
Dim As String name

Print "What is your name?"
Input name
Print "Hello, "; name; "!"

Sleep
Tip

Type it rather than pasting it. You will see auto-indentation and syntax highlighting working, which is the point of the exercise.

Save it

  1. Press Ctrl + S. Because the file has never been saved, the Save As dialog opens.
  2. Create a folder for this tutorial — C:\tiko-tutorial is fine.
  3. Name the file greet.bas and save.
  4. The tab caption changes from Untitled to greet.bas.

Now change something — add a comment at the end — and press Ctrl + S again. It saves straight away with no dialog, because the file now has a name.

Save As, and what it really does

  1. Choose File›Save As….
  2. Save it as greet2.bas.
  3. Look at the tab: it now reads greet2.bas.
Important

After Save As you are editing the new file. The original is closed and left as it was at its last save. This surprises people who expect Save As to make a backup copy and keep working on the original — it does the opposite.

Close and reopen

  1. Press Ctrl + W to close the document.
  2. Open File›Open Recent. Both files are listed.
  3. Choose greet.bas. It opens where you left it.
Note

Tiko also reopens whatever you had open when you last closed it — even though you have not created a project. Those loose files already are a project, an untitled one. Lesson 5 covers this properly.

Expected result

Two files in your tutorial folder, one of them open, and both listed under Open Recent.

Common mistakes

SymptomCause and fix
Pressing Ctrl + S opens a dialog every time.You are pressing Ctrl + Shift + S (Save All), or the document genuinely has not been saved yet.
The original file did not change after Save As.That is correct behaviour. Save As switches you to editing the new file.
The tab shows a modified marker that will not clear.The file has unsaved changes. Press Ctrl + S.
Open Recent is empty.Nothing has been opened yet in this installation — the list fills as you work.

Review

  • Ctrl + S saves; Ctrl + Shift + S saves everything.
  • Save As moves you to the new file.
  • Ctrl + W closes a document; Ctrl + Shift + W closes them all.
  • Open Recent lists files; Recent Projects lists whole workspaces.

Practice

  1. Create a third file, notes.txt, and type a few lines. Notice that it gets no syntax colouring — Tiko chose the language from the extension.
  2. Close every document with Ctrl + Shift + W, then reopen greet.bas from Open Recent.
  3. Restart Tiko and confirm your open files come back.

What's next?

In Lesson 3 you learn to edit efficiently — selections, line operations and column editing.
