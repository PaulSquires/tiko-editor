Lesson 3 — Editing text

Select, move, duplicate and comment code efficiently, including column editing.

Goal: Select, move, duplicate and comment code efficiently, including column editing.Time: 20 minutesBefore you start: Lessons 1–2.

What you will learn

  • Selecting by word, line and block.
  • Duplicating, deleting and moving lines with no selection.
  • Editing several lines at once with column mode.
  • Commenting and uncommenting blocks.

Open greet.bas and replace its contents with this:

fbinventory.bas
' inventory.bas - Lesson 3
Dim As String item1, item2, item3
Dim As Integer qty1, qty2, qty3

item1 = "bolt"
item2 = "nut"
item3 = "washer"

qty1 = 100
qty2 = 250
qty3 = 75

Print item1, qty1
Print item2, qty2
Print item3, qty3

Sleep

Save it as inventory.bas.

Selections

  1. Double-click washer. The word is selected.
  2. Triple-click the same line. The whole line is selected.
  3. Click at the start of the first Print line, then hold Shift and press ↓ twice. Three lines are selected.
  4. Press Ctrl + A to select everything, then click once to clear it.

Line operations

These work with no selection at all, which is what makes them fast.

  1. Put the caret anywhere on the qty2 = 250 line.
  2. Press Ctrl + D. A copy appears below.
  3. Press Ctrl + Y. The duplicate is removed again.
  4. Press Alt + ↑ twice. The line moves up past its neighbours.
  5. Press Alt + ↓ twice to put it back.
  6. Press Ctrl + L to select the whole line, then Ctrl + C to copy it.
Tip

With nothing selected, Ctrl + X and Ctrl + C act on the whole line. To move a line, press Ctrl + X, click where you want it, and press Ctrl + V.

Column editing

This is the technique worth practising until it is automatic.

  1. Hold Alt and drag straight down the left edge of the three Print lines, without moving right. You now have three carets stacked vertically.
  2. Type ' — an apostrophe and a space. All three lines are commented at once.
  3. Press Ctrl + Z to undo it.
  4. Now hold Alt and drag across the qty in all three qty1/2/3 declarations to select a rectangle.
  5. Type amount. All three change together.
  6. Press Ctrl + Z to undo.
Note

A zero-width column selection gives you a caret per line, which inserts. A column with width selects a rectangle, which replaces.

Commenting

  1. Select the three Print lines.
  2. Press Ctrl + /. All three are commented.
  3. Press Ctrl + Shift + /. The comments are removed.

This is easier than the column trick for commenting, and it knows the language's comment character. Use column mode for things that are not comments.

Expected result

inventory.bas is back to its original state, and you have used every editing technique above at least once.

Common mistakes

SymptomCause and fix
Dragging with Alt selects normally.Press and hold Alt before you press the mouse button.
Typing in a column selection replaced text I wanted to keep.Your selection had width. For inserting, drag straight down without moving sideways.
Ctrl + D does nothing.The editor does not have focus. Click in it, or press Ctrl + `.
Comment block used the wrong comment character.The file's language is wrong for its extension. Check the language field in the status bar.

Review

  • Ctrl + D duplicates, Ctrl + Y deletes, Alt + ↑/Alt + ↓ moves a line.
  • Cut and Copy act on the whole line when nothing is selected.
  • Alt-drag gives a column selection; a zero-width one inserts on every line.
  • Ctrl + / and Ctrl + Shift + / comment and uncomment.

Practice

  1. Use column mode to change all three item variables to part.
  2. Reorder the three Print lines into reverse order using only Alt + ↑ and Alt + ↓.
  3. Comment out the entire file, then uncomment it, using two keystrokes each way.
