Lesson 4 — Searching

Find and replace text in a file, search a whole project, and confine a search to the text you selected.

Goal: Find and replace text in a file, search a whole project, and confine a search to the text you selected.Time: 15 minutesBefore you start: Lessons 1–3.

What you will learn

  • Finding text and repeating a search with F3.
  • What Whole word and Match case actually change.
  • Replacing one match at a time, and all at once.
  • Searching every file in the project.
  • Confining a search to the selected text.

Keep inventory.bas open for this lesson.

Find

  1. Press Ctrl + F.
  2. Type qty. Matches are highlighted as you type.
  3. Press Enter repeatedly to step through them.
  4. Press Esc to close the Find bar.
  5. Now press F3. The search continues without the bar being open — and Shift + F3 goes back.
ImportantF3 is the shortcut that saves the most time. Search once, then step through matches with one key while you edit.

Whole word and case

  1. Search for item1. Three matches — the declaration, the assignment and the Print.
  2. Search for item. Many more, because it matches inside item1, item2 and item3.
  3. Turn on Whole word and search for item again. No matches, because no variable is called exactly that.

That is the difference in a nutshell, and it is the setting most often responsible for a Replace All going wrong.

Replace

  1. Press Ctrl + H.
  2. Find qty, replace with quantity.
  3. Press Replace once. One occurrence changes and the next is found.
  4. Press Replace All. Everything else changes at once.
  5. Press Ctrl + Z. The whole Replace All is undone in one step.
Tip

Replace All is one undo away, but check Whole word first. Replacing id with identifier without it will happily rewrite the middle of every word containing id.

Find in Project

  1. Press Ctrl + Shift + F.
  2. Search for Print.
  3. The Output panel opens on its Search results tab, listing every match in every file of the workspace.
  4. Click a result. That file opens with the caret on the line.

With only two or three files this seems like overkill. On a real project it is how you answer "where is this used?" in a couple of seconds.

Searching inside a selection

  1. Select the three Print lines — a multi-line selection.
  2. Press Ctrl + F. Notice two things: the search box is empty, and the Selection icon is lit. Tiko Editor turned it on for you.
  3. Search for item. Only matches inside your selection are found.
  4. Turn Selection off by clicking its icon, and search again. Now the whole file is searched.
Important

This is the safe way to run a Replace All over one procedure instead of a whole file: select the region first, then replace.

NoteTiko Editor does not support regular expressions. Searches are literal text, refined by the three latching options — Match Case, Match Whole Words and Selection.

Expected result

The file is back to using qty, and you have used Find, Replace, Find in Project and the Selection option at least once each.

Common mistakes

SymptomCause and fix
Replace All changed far more than expected.Whole word was off. Press Ctrl + Z — it undoes the whole operation — and try again.
A search finds nothing that is clearly there.Match Case, Match Whole Words or Selection is still latched on from a previous search. Look for a lit icon on the Find bar.
F3 does nothing.No search has been made yet in this session. Open Find once first.
Find in Project returns nothing.The files are not in the workspace. Lesson 5 covers this.

Review

  • Ctrl + F finds, F3 repeats, Ctrl + H replaces.
  • Ctrl + Shift + F searches every file, with results in the Output panel.
  • Whole word prevents matches inside longer words.
  • Replace All is a single undoable action.

Practice

  1. Use Replace to rename item to part throughout, then undo it.
  2. Use Find in Project to find every line containing Dim.
  3. Select just the assignment lines and use Selection to replace qty there only, leaving the Print lines untouched.
