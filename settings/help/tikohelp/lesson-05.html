Lesson 5 — Projects

Turn the files you already have into a named project, add files to it, and reopen it.

Goal: Turn the files you already have into a named project, add files to it, and reopen it.Time: 15 minutesBefore you start: Lessons 1–4.

What you will learn

  • Why every workspace is already a project.
  • Naming a workspace with Save as Project.
  • How files are categorised in the Explorer.
  • Why closing a tab does not remove a file from a named project, and how to remove one properly.
Important

Before you start, understand the central idea: in Tiko you already have a project. The files you have been editing form an untitled one. This lesson gives it a name.

Look at what you have

  1. Press Ctrl + F4 to show the Explorer.
  2. You will see the five permanent category headers — Main, Resource, Header, Module and Normal — with your files under them.
  3. At the top there is a pinned Save as Project… row. That row is telling you the workspace has no name yet.

Name the project

  1. Click Save as Project…, or choose Project›Save Project As….
  2. Save it as tutorial.tiko in your tutorial folder.
  3. The pinned row disappears and the window caption now names the project.
Note

Nothing about your files changed. The same files are in the same workspace — it now has a name, appears in Recent Projects, and can be reopened deliberately.

Add a file

  1. Press Ctrl + N to create a new file.
  2. Type the code below and save it as helpers.bi in the same folder.
fbhelpers.bi
' helpers.bi - Lesson 5
#pragma once

Declare Function Describe( ByVal qty As Integer ) As String

Function Describe( ByVal qty As Integer ) As String
    If qty = 0 Then Return "out of stock"
    If qty < 100 Then Return "low"
    Return "plenty"
End Function

Look at the Explorer. helpers.bi has been filed under Header, because Tiko categorises by extension.

Use it

Edit inventory.bas so it includes and calls the helper:

fbinventory.bas
' inventory.bas - Lesson 5
#include once "helpers.bi"

Dim As String item1, item2, item3
Dim As Integer qty1, qty2, qty3

item1 = "bolt"  : qty1 = 100
item2 = "nut"   : qty2 = 250
item3 = "washer": qty3 = 75

Print item1, qty1, Describe( qty1 )
Print item2, qty2, Describe( qty2 )
Print item3, qty3, Describe( qty3 )

Sleep

Tabs versus project membership

  1. Close helpers.bi with Ctrl + W.
  2. Look at the Explorer. The file is still listed.
  3. Click it. It opens again.
Important

A tab is a view of a file. In a named project, closing the tab stops displaying the file; it does not take it out of the project. It is still compiled, still searched by Find in Project, and still listed.

To take a file out for real, right-click it in the Explorer — or right-click its tab — and choose Remove from project. It is removed from the project, not deleted from disk.

Note

You did this in an untitled workspace earlier and it behaved differently: with no project to remove from, Remove from project is not offered and closing the tab is what takes the file out. Naming the project is what separates the two ideas.

Reopen the project

  1. Choose Project›Close Project.
  2. Everything closes and you are given a fresh untitled workspace — because there is always a workspace.
  3. Choose Project›Recent Projects and pick tutorial.
  4. Your files come back.

Expected result

A named project, tutorial.tiko, containing inventory.bas and helpers.bi, which you can close and reopen at will.

Common mistakes

SymptomCause and fix
The Save as Project row is not there.The workspace already has a name. Check the window caption.
A new file went into the wrong category.Categories come from the file extension. Change the category from the Explorer's context menu.
Closing a tab seemed to lose a file.In a named project it is still in the Explorer — click it to reopen. On an untitled workspace, closing really does remove it.
There is no Remove from project command on the menu.The workspace is still untitled. Save it as a project first.
Find in Project misses a file.That file is not in the workspace. Add it with Project›Add Files to Project….

Review

  • Every set of open files is a project; naming it is a save.
  • The untitled workspace is restored automatically at start-up.
  • Files are categorised by extension into Main, Resource, Header, Module and Normal; Main and Resource hold exactly one file each.
  • Tabs and project membership are separate things.

Practice

  1. Add notes.txt from Lesson 2 to the project and see which category it lands in.
  2. Close every tab, then reopen both source files from the Explorer.
  3. Close the project, create two throwaway files in the new untitled workspace, then reopen tutorial and confirm your work is intact.

What's next?

In Lesson 6 you compile and run the program. You need a FreeBASIC compiler installed for this one.
