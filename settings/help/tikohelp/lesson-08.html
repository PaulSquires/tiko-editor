Lesson 8 — Customization

Choose a theme and font, enable the display aids you like, and remap a keyboard shortcut.

Goal: Choose a theme and font, enable the display aids you like, and remap a keyboard shortcut.Time: 15 minutesBefore you start: Lessons 1–3. No compiler needed.

What you will learn

  • Switching themes and what a theme covers.
  • Setting the editor font, size and line spacing.
  • Why zoom and font size are different things.
  • Remapping and resetting a keyboard shortcut.
  • Which files hold your configuration.

Try the themes

  1. Press Ctrl + Shift + T, or choose File›Settings›Themes….
  2. Try several themes — a dark one, a light one, a high-contrast one.
  3. Settle on one you like and choose OK.

Notice that the whole application changed, not just the code area: the menus, panels, tabs and status bar all follow the theme.

Set the font

  1. Open File›Settings›Options… and go to the font settings.
  2. Change the size from 11 to 13. Choose OK and see the difference.
  3. Try a different monospaced font if you have one installed.
  4. Set extra line spacing to 3 and see how much easier dense code is to read.
Important

Use a monospaced font. Column selection, indent guides and the right-edge marker all assume every character is the same width.

Zoom is not the font size

  1. Press Ctrl + + three times, then Ctrl + - three times.
  2. Press Ctrl + 0 to reset.

Zoom is temporary and per-session; the font setting is permanent. Use zoom when you want a quick overview or need to read something closely, and the font setting for how you work all day.

Turn on the display aids

Open the options dialog and enable these, then look at your code:

OptionWhat you will see
Indent guidesFaint vertical lines at each indent level.
Highlight current lineThe caret's line tinted.
Right edgeA vertical line at column 80.
Brace highlightMatching parentheses highlighted as you move past them.
Occurrence highlightEvery other use of the word under the caret marked.

Keep the ones that help and turn off the ones that distract. There is no wrong answer.

Remap a shortcut

  1. Press Ctrl + K to open the Keyboard Shortcuts dialog.
  2. Type duplicate in the filter box to find Duplicate Line.
  3. Select it and choose Modify.
  4. Press Ctrl + Shift + D in the capture field.
  5. Choose OK, then OK again.
  6. Test it in the editor. Then reopen the dialog, select the command and choose Reset to restore Ctrl + D.
Note

Try assigning a keystroke that is already in use — Ctrl + S, say. The dialog refuses it and tells you why, rather than silently taking it from the other command.

See where it is all stored

  1. Close Tiko.
  2. Open settings\settings.ini in Notepad and find EditorFontsize and Theme. Those are the changes you just made.
  3. Open settings\keybindings.ini. If you left a remapping in place, it is the only thing in there — Tiko stores overrides, not defaults.
  4. Close both without saving, and start Tiko again.
Tip

Copy the settings folder to another machine and your entire setup goes with it — theme, shortcuts, preferences and all.

Expected result

Tiko looks the way you want, you have remapped and reset a shortcut, and you know which files hold your configuration.

Common mistakes

SymptomCause and fix
Code no longer lines up after changing font.You chose a proportional font. Pick a monospaced one.
A remapped shortcut does nothing.You closed the dialog with Cancel, which discards every change. Use OK.
A keystroke was refused.Another command already owns it. Choose a different one, or rebind the other command first.
Hand-edited settings.ini and the changes vanished.Tiko rewrites the file when it exits. Close Tiko before editing it.

Review

  • Themes cover the whole application, not just the editor.
  • Zoom is temporary; the font setting is permanent.
  • Every command can be remapped, and conflicts are refused rather than silently resolved.
  • Everything is stored in the settings folder beside tiko.exe.

Practice

  1. Try every bundled theme and keep the one you like best.
  2. Give Format Document (currently Shift + Alt + F) a shortcut you find easier, then reset it.
  3. Back up your settings folder somewhere safe.
