Line and block operations

Duplicating, deleting, moving and selecting lines; commenting blocks; and converting the case of a selection.

These commands act on whole lines or blocks, and save a great deal of selecting and dragging. Most work with no selection at all, acting on the current line.

Line commands

CommandShortcutWhat it does
Duplicate LineCtrl + DCopies the current line and inserts the copy below it.
Delete LineCtrl + YRemoves the current line entirely.
Move Line UpAlt + ↑Swaps the current line with the one above. Moves the whole selection if there is one.
Move Line DownAlt + ↓Swaps it with the line below.
Select LineCtrl + LSelects the whole current line.
New line belowCtrl + EnterOpens a line beneath the current one from anywhere on it.
TipAlt + ↑ is the fastest way to reorder statements or move a procedure — select the lines and hold the shortcut down.

Commenting

CommandShortcutWhat it does
Comment BlockCtrl + /Comments out every selected line, or the current line.
UnComment BlockCtrl + Shift + /Removes the comment marks again.

The comment character used matches the current file's language — an apostrophe for FreeBASIC, // for C-family files.

Changing case

CommandShortcutResult
UppercaseCtrl + Alt + UCOUNT
LowercaseCtrl + Alt + Lcount
Mixed caseCtrl + Alt + XCount

These act on the selection. With nothing selected, there is nothing to convert.

Note

To normalise the case of keywords throughout a file, use the formatter's case rules instead — see Code formatting. These commands change whatever is selected, keyword or not.

Indenting blocks

Tab and Shift + Tab indent and unindent every line of a multi-line selection. See Indentation.

Commands Tiko Editor does not have

For completeness, because they exist in some other editors and are worth not hunting for: Tiko Editor has no Sort Lines, Join Lines or Transpose Lines command, and no standalone Trim Trailing Whitespace command.

Trailing whitespace is handled two other ways:

RouteWhat it doesWhere
Strip line ending whitespace when savingRemoves trailing spaces and tabs from every line each time you save. Set it once and forget it.File›Settings›Options… ▸ Advanced Code Editor
Trim trailing whitespaceA formatter rule, applied when you run one of the Format commands.Edit›Format›Format Options…
Tip

Turning on Strip line ending whitespace when saving is the low-effort option — it keeps a file clean without you ever running a command, and it keeps trailing-space noise out of your diffs.
