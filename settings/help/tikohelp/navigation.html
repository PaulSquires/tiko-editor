Navigation

Goto Definition, navigation history, symbol search, procedure stepping, and jumping between related and open files.

Tiko gives you several ways to move around, from the whole-project symbol search down to stepping between procedures in one file. Learning two or three of these makes far more difference to day-to-day speed than any other feature.

Goto Definition

Put the caret on any symbol — a procedure name, a type, a variable — and press F12. Tiko jumps to where that symbol is defined, opening the file if necessary.

This works across the whole project because Tiko's parser has already indexed every file. It is the single most useful navigation command in the editor.

Note

For a procedure with a separate declaration and implementation, Goto Definition takes you to the implementation — the code, rather than the prototype.

Navigation history

Every jump is recorded, so you can retrace your steps the way you would in a browser.

CommandShortcut
Go BackAlt + ←
Go ForwardAlt + →
TipF12 then Alt + ← is the core navigation loop: dive into a definition, read it, and come straight back to where you were. Learn this pair first.

Search Symbol — the fuzzy finder

Ctrl + P opens Search Symbol, a popup that appears just under the tab strip. It is Tiko's universal "go to anything" command, and it is a fast fuzzy finder rather than a plain substring filter.

What it searches

One list, built from two sources and ranked together:

  • Every file the symbol database knows about — including include files you have never opened in the editor. This is a superset of the files with tabs open.
  • Every procedure and type in the project — subs, functions, types and enumerations, shown by their qualified name, so a method inside a type appears under its full name rather than on its own.

Leave the box empty and it simply lists all the files, which makes it a file switcher as well as a symbol finder.

How fuzzy matching works

You do not have to type a contiguous piece of the name. The characters you type need only appear in order somewhere in it — so fpm finds frmPanelMenu, and sdoc finds SaveDocument.

Every candidate is then scored, and the list is sorted best-first. The scoring favours matches that look deliberate:

  • characters at the start of a word, or just after an underscore or a capital, count for more than characters in the middle of one;
  • consecutive matched characters score better than scattered ones;
  • a shorter name matching the same letters outranks a longer one.

In the results, the characters your search matched are highlighted within each name, so you can see at a glance why a row is in the list and whether the top hit is the one you meant.

Tip

Type the initials of a camel-case or underscore-separated name. Three or four well-chosen letters usually put the item you want at the top of the list — that is what fuzzy matching is for, and it is much faster than typing a prefix.

Note

The result list is capped, so an extremely broad search shows the best matches rather than everything. Type another character or two and the item you want rises into view.

Moving between procedures

CommandShortcut
Next procedureCtrl + PgDn
Previous procedureCtrl + PgUp

These step through the subs and functions of the current file in order — a quick way to skim a file's structure without leaving the keyboard.

Going to a line number

ImportantThere is no Goto Line dialog. Tiko has no command that asks you to type a line number, because in practice you never need one — everything that knows about a line number takes you there directly.
You haveDo this
A compiler error or warningClick the row in the Output panel. It opens the file and puts the caret on the line.
A search result from Find in ProjectClick the row. Same behaviour.
A TODO commentClick it in the Output panel's TODO tab.
A procedure or type nameSearch Symbol (Ctrl + P), or F12 on the name itself.
A bookmarkF2 cycles through them; the bookmarks list shows the file and line of each.
A rough idea of where it isThe function list (F4) to jump by procedure, or Ctrl + PgDn / Ctrl + PgUp to step between them.

The status bar always shows the current line and column, so you can still tell someone else where you are.

Switching between related files

Tiko knows about the conventional relationships between the files of a FreeBASIC project, and can hop between them:

CommandShortcutGoes to
Goto Header FileCtrl + Shift + HThe header (.bi) matching the current source file.
Goto Code FileCtrl + Shift + CThe source (.bas) matching the current header.
Goto Main FileCtrl + Shift + MThe project's main module.
Goto Resource FileCtrl + Shift + RThe project's resource script.
TipCtrl + Shift + H and Ctrl + Shift + C form a toggle between a module and its header — the pairing you move between most often while writing code.

Switching between open files

  • Ctrl + Tab and Ctrl + Shift + Tab cycle through the open tabs.
  • The tab list button at the end of the tab strip lists every open document.
  • Clicking a file in the Explorer brings its tab forward if it is already open.
