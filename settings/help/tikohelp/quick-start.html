Quick Start

Install Tiko Editor, learn the interface, and work through editing, searching, building, running and debugging a program — in about 25 minutes.

Note

This walkthrough takes 20–30 minutes and touches every part of the editor you will use daily. If you would rather learn in smaller pieces with exercises, take the ten-lesson tutorial instead — it covers the same ground more slowly.

1. Install and launch

Tiko Editor does not use an installer. Unpack the distribution into any folder you can write to and run tiko-editor.exe from there.

  1. Unpack the archive into a folder — for example C:\tiko-editor. Avoid C:\Program Files: Tiko Editor writes its settings beside the executable, and that location is protected.
  2. Double-click tiko-editor.exe.
  3. The main window opens with an empty untitled workspace.
Warning

Run tiko-editor.exe from the folder you unpacked, not from a copy you moved elsewhere on its own. Tiko Editor finds its themes, settings and keyword files relative to its own location, so a stray copy starts with no theme and no configuration.

2. Get your bearings

The window has five regions. Spend a moment locating each one.

Tip

Two shortcuts worth learning immediately: Ctrl + B toggles the side panel and Ctrl + F9 toggles the Output panel. Both give the editor the whole window when you need room.

3. Create your first file

  1. Choose File›New or press Ctrl + N. A new untitled document opens in a new tab.
  2. Type the short program below. Notice that keywords colour themselves as you type, and that pressing Enter after For automatically indents the next line.
fbhello.bas
' hello.bas - a first FreeBASIC program
Dim As Integer i

For i = 1 To 5
    Print "Line "; i
Next i

Print "Press any key to finish."
Sleep

4. Save, and Save As

  1. Press Ctrl + S. Because the file has never been saved, the Save As dialog opens.
  2. Choose a folder, name the file hello.bas, and save. The tab caption changes from Untitled to the file name.
  3. Type another line, then press Ctrl + S again. This time it saves silently — no dialog.
  4. To write a copy under a different name, use File›Save As…. The editor then continues editing the new file, not the original.
Note

An asterisk or modified marker on a tab means the file has unsaved changes. Ctrl + Shift + S saves every modified document at once.

5. Reopen recent work

Tiko Editor keeps two separate recent lists, and the distinction matters:

  • File›Open Recent — individual files you have opened.
  • Project›Recent Projects — whole workspaces, restoring every file that was open.

Each list ends with Clear this list if you want to reset it. Tiko Editor also reopens your last workspace automatically when it starts, so in normal use you rarely need either list.

6. Edit: undo, clipboard, selection

The basics behave exactly as they do in every Windows editor:

ActionShortcutNotes
UndoCtrl + ZUnlimited within a session.
RedoCtrl + Shift + ZReapplies what Undo removed.
CutCtrl + XWith no selection, acts on the whole line.
CopyCtrl + C
PasteCtrl + V
Select allCtrl + A
Select the current lineCtrl + LRepeat to extend downward.
Delete the current lineCtrl + YNo selection needed.
Duplicate the current lineCtrl + D
Move the line up or downAlt + ↑ / Alt + ↓Moves the selection if there is one.

Selecting text

  • Drag with the mouse, or hold Shift and use the arrow keys.
  • Double-click selects a word; triple-click selects a line.
  • Column (rectangular) selection: hold Alt while dragging, or hold Alt + Shift and use the arrow keys. Typing then edits every selected line at once.
  • Multiple selections: hold Ctrl and drag or click to add further selections, then type to edit them all together.
Tip

Column mode is the quickest way to add the same prefix to a run of lines — select the zero-width column down the left edge and type once.

7. Search and replace

  1. Press Ctrl + F to open Find. Type Print.
  2. Press F3 to jump to the next match and Shift + F3 for the previous one — these work even after the Find bar has closed.
  3. Press Ctrl + H for Replace. Enter what to find and what to put in its place, then use Replace for one match at a time or Replace All for every match.
  4. Press Ctrl + Shift + F for Find in Project to search every file in the workspace at once. Results collect in the Output panel; click one to jump straight to it.
Note

Find offers three latching options — Match Case, Match Whole Words and Selection. Tiko Editor does not support regular expressions. See Find and Replace.

9. Check your compiler

ImportantThere is nothing to install. Tiko Editor ships with the most recent FreeBASIC toolchain already set up, so you can skip this step entirely and go straight to building. It is here so you know where the setting lives.

Compiler toolchains are subfolders of the toolchains\ folder beside tiko-editor.exe, and each one holds both fbc32.exe and fbc64.exe. To see which is selected, or to switch to another you have installed:

  1. Open File›Settings›Options….
  2. Select the Compiler page.
  3. The list shows every toolchain found in toolchains\. Click one to select it.
  4. Choose OK.
Note

Whether you build 32-bit or 64-bit is decided by the build configuration, not by the toolchain — every toolchain contains both compilers. See Build configurations.

10. Build and run

With a compiler configured, the whole cycle is three keys:

CommandShortcutWhat it does
Build and ExecuteF5Compiles, and runs the result if the compile succeeded. The command you will use most.
CompileCtrl + F5Compiles without running.
Rebuild AllCtrl + Alt + F5Rebuilds everything from scratch.
Quick RunCtrl + Shift + F5Compiles and runs the current file on its own, ignoring the project.
Run ExecutableShift + F5Runs the last successful build without recompiling.
Compile ModuleCtrl + F7Compiles only the current module.
  1. Press F5.
  2. The Output panel opens on its Compiler tab and shows the build.
  3. If the build succeeds, your program runs.
  4. If it fails, each error appears as a line in the panel. Click an error to jump straight to the file and line that caused it.
Tip

Quick Run (Ctrl + Shift + F5) is ideal for a scratch file — it builds and runs just that file with no project set-up at all.

11. Debug

Tiko Editor has a real source-level debugger built in, not just a console window.

  1. Click in the margin beside a line, or press F9, to set a breakpoint. A marker appears in the margin.
  2. Press F6 to start debugging. The program runs until it reaches your breakpoint and then stops, with the current line marked.
  3. Step through the code: F11 steps into calls, F10 steps over them, Shift + F11 steps out of the current procedure.
  4. Hover the mouse over a variable to see its value, or read the debugger panes — globals, locals, the call stack and your watch expressions.
  5. Press Shift + F6 to stop debugging.
Note

Debugging needs a build that carries debug information. Tiko Editor selects an appropriate debug build automatically. See Debugging for the full story.

12. Make it yours

Two quick customizations before you finish:

Pick a theme

  1. Open File›Settings›Themes… (or press Ctrl + Shift + T).
  2. Choose from the fourteen bundled themes — light and dark variants of several families.
  3. Apply, and the whole interface changes with it.

Set the editor font

  1. Open File›Settings›Options….
  2. On the editor page, choose the font name, size and character set. The default is Consolas at 11 point.
  3. Choose OK.
TipCtrl + + and Ctrl + - zoom the editor text temporarily without changing the configured font size; Ctrl + 0 resets the zoom.

13. Close down

  • Ctrl + W closes the current document; Ctrl + Shift + W closes them all.
  • Alt + F4 exits Tiko Editor. You are prompted to save anything modified.
  • Your workspace — which files were open, and the window layout — is restored the next time you start.
