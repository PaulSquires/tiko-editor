Settings and configuration files

Where Tiko stores everything it remembers, how to edit those files, back them up, move them between machines and reset them.

Everything Tiko remembers is a plain file next to tiko.exe. There is nothing in the registry and nothing in your user profile, which is what makes Tiko portable.

The files

FileHolds
settings\settings.iniEvery editor setting: fonts, colours, editing behaviour, window geometry, panel layout, the compiler path and the recent-file lists.
settings\keybindings.iniYour keyboard shortcut overrides. Only overrides — defaults live in the program.
settings\default.tikoThe untitled workspace, so loose files are restored on start-up.
settings\themes\*.themeColour themes.
settings\languages\*.langInterface translations.
settings\keywords\*.txtSyntax highlighting keyword lists, which also supply autocomplete entries and canonical keyword spellings.

The settings file

settings.ini is a conventional INI file, grouped into sections. It is written when you choose OK in a settings dialog and when Tiko exits.

inisettings\settings.ini (extract)
[Editor]
SyntaxHighlighting=-1
AutoComplete=-1
TabSize=4
TabIndentSpaces=-1
EditorFontname=Consolas
EditorFontsize=11
Theme=default_dark.theme
LocalizationFile=english.lang

[Startup]
StartupMaximized=-1
ShowPanel=1
ShowPanelWidth=236
ShowOutputPanel=0
Important

Boolean settings use the BASIC convention: -1 is true and 0 is false. A setting written as 1 is not what a true value looks like here.

Every key is documented in the configuration reference.

Editing settings by hand

WarningClose Tiko before editing settings.ini. The editor writes the whole file when it exits, so changes made while it is running are overwritten.

Most settings are better changed through the options dialog, which validates what you enter. Editing the file directly is useful for bulk changes and for values you want to copy between installations.

Backing up, and moving to another machine

Copy the settings folder. That is the entire backup — settings, shortcuts, themes, languages and keyword lists.

To transferCopy
EverythingThe whole settings folder.
Just your shortcutssettings\keybindings.ini
Just a themeThe .theme file from settings\themes
Just your editor preferencessettings\settings.ini — but see the note below.
Notesettings.ini also holds window positions and the recent-file lists, which are specific to a machine. Copying it wholesale to a computer with a different screen layout may put the window somewhere awkward; View›Restore Main Window Size fixes that.

Resetting to defaults

  1. Close Tiko.
  2. Rename settings.ini to settings.ini.bak — rename rather than delete, so you can go back.
  3. Start Tiko. It creates a fresh file with default values.

To reset only the keyboard, delete keybindings.ini instead. To reset only the workspace, delete default.tiko.

Running from removable media

Because nothing is stored outside its own folder, Tiko runs from a USB stick or a network share with your full configuration intact. Copy the folder, run tiko.exe from it, and the editor you get is the editor you set up.

Warning

Do not install Tiko into C:\Program Files. That location is write-protected for ordinary users, and Tiko needs to write its settings beside the executable.

Multiple installations

Two copies of Tiko in different folders have completely separate settings, themes and workspaces. This is deliberate and useful — you might keep a customised installation for one project and a stock one for another — but it also means that which copy you launch decides which configuration you get. If a setting seems not to have taken effect, check which tiko.exe you ran.
