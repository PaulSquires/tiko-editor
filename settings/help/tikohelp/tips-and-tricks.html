Tips and tricks

Power-user habits, keyboard and mouse tricks, and the features people most often miss.

Habits and shortcuts that repay the time it takes to learn them, roughly in order of how much difference they make.

The five habits worth building first

  1. F12 then Alt + ←. Jump to a definition, read it, come straight back. This one pair replaces most scrolling and most file-switching.
  2. Search once, then F3. Close the Find bar and step through matches with a single key while you edit.
  3. Ctrl + P for anything you can name. If you know what a procedure is called, you do not need to know where it lives.
  4. Cut and copy with nothing selected. Both act on the whole line, so moving a line is Ctrl + X, click, Ctrl + V.
  5. Shift + F8 before you read an unfamiliar file. Fold everything, see the structure, then expand what matters.

Editing tricks

  • Zero-width column selections insert. Alt-drag straight down without moving sideways to get one caret per line, then type once to prefix every line.
  • Home is smart. It goes to the first non-blank character; press it again for column one. On indented code that is almost always what you meant.
  • Ctrl + Enter opens a line below from anywhere on the current one. No need to press End first.
  • Ctrl + L repeatedly extends the selection downward, so three presses selects three lines.
  • Hold Alt + ↑ or Alt + ↓ to reorder several lines at once — select them first and the whole block moves.
  • Paste is always plain text. Code copied from a web page or a document arrives without its formatting.

Search tricks

  • Select text before pressing Ctrl + F and it becomes the search term.
  • Use Find in Project as a preview for Replace All. Search first, see how many places would change and whether they are all what you expect, then replace.
  • Select first, then search. Opening Find with a multi-line selection turns on Selection automatically, so a Replace All is confined to the region you highlighted — the safe way to rename inside one procedure only.
  • Watch for latched icons. Match Case, Match Whole Words and Selection stay lit until you turn them off, and are the usual reason a search stops finding what you expect.

Navigation tricks

  • Ctrl + Shift + H and Ctrl + Shift + C toggle between a module and its header — the pair you move between most while writing code.
  • Ctrl + PgDn and Ctrl + PgUp step between procedures without leaving the keyboard.
  • Bookmarks for now, TODO comments for later. Bookmarks are private and transient; TODO comments live in the source and are visible to everyone.
  • The navigation history survives file switches, so Alt + ← works even after you have wandered through several files.

Mouse tricks

  • Ctrl + wheel zooms; Shift + wheel scrolls horizontally.
  • Double-click selects a word; triple-click selects a line.
  • Click in the left margin to select a line — or to toggle a breakpoint, if you enable that option.
  • Double-click the Output panel's tab strip to minimise it, and click a tab to bring it back.
  • Drag tabs to reorder your documents.

Build and debug tricks

  • Quick Run (Ctrl + Shift + F5) turns Tiko Editor into a scratchpad. New file, ten lines, one keystroke — no project needed.
  • Run to Cursor (Ctrl + F10) instead of a temporary breakpoint. Nothing to set and nothing to remember to clear.
  • Watch expressions, not variables. rows(i).total tells you far more inside a loop than its parts separately.
  • Put a breakpoint inside the branch you doubt. If it never fires, you have learned that the branch is not taken — which is frequently the bug.
  • Compile›Command Line… answers most "why did it build like that?" questions in one glance.

Configuration tricks

  • Back up the settings folder. It is your entire setup, and restoring it is a copy.
  • Keep two installations if you work on projects with different conventions — separate folders have entirely separate settings.
  • Give your build configurations shortcuts so switching between debug and release is one keystroke.
  • Bind the commands that ship unbound. Format Selection, Project Options and the panel expand/collapse commands all have no default shortcut and are free for you to claim.
  • Add your library's function names to the keyword lists. They then highlight and appear in autocomplete.

Lesser-known features

FeatureWhy it is useful
Open File As TemplateStart from boilerplate without any risk to the original file.
Insert File (Ctrl + I)Drop a licence header or a block of boilerplate into the current file.
Notes tabA scratchpad saved with the project — build reminders, open questions.
Unused SymbolsA periodic tidy-up: dead procedures and stale variables.
Duplicate (file)Fork a file to experiment without touching the original.
Ctrl + `Return focus to the editor from wherever it has ended up.
View›Restore Main Window SizeRescue a window that has ended up off screen or badly sized.
