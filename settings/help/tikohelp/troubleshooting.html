Troubleshooting

Symptoms, causes and fixes for start-up, build, debugger, file, search, editing and layout problems.

Symptoms, causes and fixes. Work down each list — the first item is the most common cause.

Tiko will not start, or starts wrong

SymptomCause and fix
It starts with no colours and the menus look wrong.You launched a copy of tiko.exe away from its settings folder. Run it from the folder you unpacked.
It reports a missing DLL.The editing, parser or debugger DLLs are not beside the executable. Restore the full distribution.
Settings are forgotten every time.Tiko cannot write to its own folder. Move it out of C:\Program Files, or grant write permission.
The window opens off screen or at a strange size.Stored geometry from another monitor arrangement. Choose View›Restore Main Window Size, or close Tiko and delete the [Startup] geometry keys from settings.ini.
A change I made in the options had no effect.You may have two installations and be launching the other one. Each folder has its own settings — check which tiko.exe you ran.

Compiler and build problems

SymptomCause and fix
“Compiler not found”, or the build does nothing.The compiler path is unset or wrong. Set it in File›Settings›Options… on the Compiler page.
The build fails with errors that make no sense.Fix the first error and rebuild. One early mistake commonly produces a cascade.
The build succeeds but runs old behaviour.A file was not saved. Enable Compile autosave.
Builds behave inconsistently after changing switches.Stale object files. Use Rebuild All (Ctrl + Alt + F5).
The program window flashes and disappears.Your program ended immediately. Add Sleep at the end, or run it from a console.
Linker errors about a library or an architecture mismatch.A 32-bit program cannot link a 64-bit library. Check which compiler Tiko is configured to use.

Debugger problems

SymptomCause and fix
Debugging will not start.The executable carries no debug information. Select a Debug build configuration and rebuild.
Breakpoints are never hit.The code is not reached, or the executable is stale — rebuild. Confirm by putting a breakpoint on the first line of the program.
A breakpoint moved when I set it.That is intended: the line generated no executable code, so it moved to the next line that did.
Break does not stop the program.It stops at the next line of your source; a program blocked in a library call will not stop until it returns. Use Shift + F6 to stop outright.
A variable shows an implausible value.It may not be initialised yet, or you are looking at the wrong stack frame. Check which frame is selected in the call stack.
Stepping lands in code I did not write.You used F11 on a library call. Shift + F11 steps back out.

File and encoding problems

SymptomCause and fix
Accented or non-Latin characters display as garbage.Wrong encoding. Change it from the status bar; UTF-8 is usually correct.
A file will not save.It is read-only, open in another program, or on a disconnected network drive. Use File›Save As… to write it elsewhere and rescue your work.
Line endings look wrong in another tool.Mixed or unexpected line endings. Convert the file from the status bar.
A file changed on disk and Tiko did not notice.Enable Detect external file changes in the options.
Unsaved work was lost after a crash.There is no crash-recovery store. Enable Auto save files, and use version control.

Search problems

SymptomCause and fix
A search finds nothing that is obviously there.Match case, Whole word or Regular expression is still on from an earlier search.
Find in Project misses files.Those files are not in the workspace. Add them with Project›Add Files to Project….
A search containing a bracket or a full stop behaves oddly.Regular expression mode is on and those characters are pattern syntax. Turn it off, or escape them with \.
Replace All changed too much.Ctrl + Z undoes the whole operation. Enable Whole word and repeat.

Editor behaviour

SymptomCause and fix
Autocomplete or code tips do not appear.They are disabled in the options, or the file declaring the symbol is not in the workspace so the parser has not indexed it.
Goto Definition does nothing.Same cause — the defining file must be part of the project.
The function list is empty.The active file has no procedures the parser recognised, or its language is set incorrectly. Check the status bar.
Typing feels slow on a very large file.Turn off occurrence highlighting and, if necessary, syntax highlighting. Splitting a very large file is usually the better answer.
Tab inserts the wrong thing.Check Tab indents with spaces and Tab size.
Code alignment looks wrong.You are using a proportional font. Choose a monospaced one.

Appearance and layout

SymptomCause and fix
Text is unreadable in a theme.Switch theme, or adjust the offending colour in the theme editor. A contrast theme is the quickest fix.
A panel has disappeared.Ctrl + B for the side panel, Ctrl + F9 for the Output panel.
The Output panel is a thin strip.It is minimised. Click a tab to restore it, or drag its splitter.
A custom theme was replaced after an update.Shipped themes may be overwritten by an update. Save customised themes under a new name.
The layout is unusable after resizing.View›Restore Main Window Size returns the window to its default.

Starting over

When something is badly wrong and you want a clean slate:

  1. Close Tiko.
  2. Rename settings\settings.ini to settings.ini.bak. Rename rather than delete, so you can put it back.
  3. Start Tiko. A fresh settings file is created.
  4. If the problem is specifically keyboard-related, delete settings\keybindings.ini instead. If it is workspace-related, delete settings\default.tiko.

Reporting a problem

Include:

  • the version from Help›About;
  • your Windows version, and whether you run a 32- or 64-bit Tiko;
  • the exact steps that reproduce the problem;
  • what you expected and what happened instead;
  • any message text, copied rather than described.
