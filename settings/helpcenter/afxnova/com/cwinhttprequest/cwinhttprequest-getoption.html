CWinHttpRequest.GetOptionmethod

Retrieves a Microsoft Windows HTTP Services (WinHTTP) option value.

COMmethoddocumented

Syntax

FUNCTION GetOption (BYVAL nOption AS WinHttpRequestOption) AS DVARIANT

Parameters

NameDescription
nOptionValue of type WinHttpRequestOption that specifies the option to retrieve.

Return value

Variant that contains the option value.

Description

Retrieves a Microsoft Windows HTTP Services (WinHTTP) option value.

Example

#cmdline "-s console" #include once "AfxNova/CWinHttpRequest.inc" using AfxNova

' // Create an instance of the CWinHttp class DIM pWHttp AS CWinHttpRequest

' // Open an HTTP connection to an HTTP resource pWHttp.Open "GET", "http://microsoft.com"

' // Specify the user agent pWHttp.SetOption(WinHttpRequestOption_UserAgentString, "A WinHttpRequest Example Program")

' // Send an HTTP request to the HTTP server pWHttp.Send

IF pWHttp.GetLastResult = S_OK THEN ' // Get user agent string. PRINT pWHttp.GetOption(WinHttpRequestOption_UserAgentString) ' // Get URL PRINT pWHttp.GetOption(WinHttpRequestOption_URL) ' // Get URL Code Page. PRINT pWHttp.GetOption(WinHttpRequestOption_URLCodePage) ' // Convert percent symbols to escape sequences. PRINT pWHttp.GetOption(WinHttpRequestOption_EscapePercentInURL) END IF
