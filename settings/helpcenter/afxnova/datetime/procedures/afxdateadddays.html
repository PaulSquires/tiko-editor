AfxDateAddDaysfunction

Adds the specified number of days to a given date.

DateTimefunctionAfxTime.incdocumented

Syntax

FUNCTION AfxDateAddDays (BYVAL nDay AS LONG, BYVAL nMonth AS LONG, BYVAL nYear AS LONG, BYVAL nDays AS LONG) AS LONG

Parameters

NameDescription
nDayA day number (1-31).
nMonthA month number (1-12).
nYearA four digit year.
nDaysThe number of days to add (or subtract, if it is negative).

Return value

The new date in Julian format. To convert it to Gregorian, call functions such AfxJulianToGregorian or AfxJulianToGregorianStr.

Description

Adds the specified number of days to a given date.
