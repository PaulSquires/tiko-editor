CFileSys.GetFolderDateLastAccessedmethod

Returns the date and time that the specified folder was last accessed.

File ManagementmethodCFileSys.incdocumented

Syntax

FUNCTION GetFolderDateLastAccessed (BYREF dwsFolder AS WSTRING) AS DATE

Parameters

NameDescription
wszFolderThe path to a specific folder.

Return value

DATE_. The date and time that the folder was last accessed. This is a Date Serial number that can be formatted using the DateTimeToString method or the Free Basic's Format function.

Description

Returns the date and time that the specified folder was last accessed.

Example

#INCLUDE ONCE "AfxNova/CFileSys.inc" DIM pFileSys AS CFileSys DIM nDate AS DATE_ = pFileSys.GetFolderDateLastAccessed("C:\MyPath) PRINT pFilesys.DateTimeToString(nDate)
