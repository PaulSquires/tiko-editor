CFileSys.SetFolderNamemethod

Sets the name of a specified folder.

File ManagementmethodCFileSys.incdocumented

Syntax

FUNCTION SetFolderName (BYREF wszFolder AS WSTRING, BYREF wszName AS WSTRING) AS HRESULT

Parameters

NameDescription
wszFolderThe path to a specific folder.
wszNameThe new name of the folder.

Return value

HRESULT. S_OK (0) on success, or an error code on failure.

Description

Sets the name of a specified folder.

Remarks

You only have to pass the new name of the folder, not the full path.

Example

#INCLUDE ONCE "AfxNova/CFileSys.inc" DIM pFileSys AS CFileSys pFileSys.SetFolderName("c:\MyFolder", "NewName")
