CIniFile.GetKeyNamesmethod

Returns a safe array with the names of all the keys of the specified section.

File ManagementmethodCIniFile.incdocumented

Syntax

FUNCTION GetKeyNames () AS CSafeArray

Return value

DSAFEARRAY. The names of all the keys of the specified section.

Description

Returns a safe array with the names of all the keys of the specified section.

Example

DIM cIni AS CInifile = "Test.ini" DIM dsa AS DSafeArray = cIni.GetKeyNames("Test") FOR i AS LONG = dsa.LBound TO dsa.UBound print dsa.GetStr(i) NEXT
