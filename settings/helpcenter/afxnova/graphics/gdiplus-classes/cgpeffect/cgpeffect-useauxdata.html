CGpEffect.UseAuxDatamethod

GraphicsmethodCGpEffect.incdocumented

Syntax

SUB UseAuxData (BYVAL useAuxDataFlag AS BOOL)
Also documented as UseAuxDara — one description covers them all.

Parameters

NameDescription
useAuxDataFlagSet to TRUE to specify that ApplyEffect should return a pointer to its auxiliary data; FALSE otherwise.

Description

Sets or clears a flag that specifies whether the ApplyEffect method of the CGpBitmapclass should return a pointer to the auxiliary data that it creates.
