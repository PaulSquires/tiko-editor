Parameters

NameDescription
pwszNameName of the font family. For example, Arial.ttf is the name of the Arial font family.
pFontCollectionOptional. Pointer to a FontCollection object that specifies the collection that the font family belongs to. If FontCollection is NULL, this font family is not part of a collection. The default value is NULL.

Creates a FontFamily object based on a specified font collection.
