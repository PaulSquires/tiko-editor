CGpPen.SetColormethod

Sets the color for this **Pen** object.

GraphicsmethodCGpPen.incdocumented

Syntax

FUNCTION SetColor (BYVAL colour AS ARGB) AS GpStatus

Parameters

NameDescription
colourARGB color that specifies the color for this Pen object.

Return value

If the function succeeds, it returns Ok, which is an element of the GpStatus enumeration.

If the function fails, it returns one of the other elements of the GpStatus enumeration.

Description

Sets the color for this Pen object.

Example

' ======================================================================================== ' The following example creates a red pen and draws a line. The code then sets the pen's ' color to blue and draws a second line. ' ======================================================================================== SUB Example_SetColor (BYVAL hdc AS HDC)

' // Create a graphics object from the window device context DIM graphics AS CGpGraphics = hdc ' // Set the scale transform graphics.ScaleTransformForDpi

' // Create a red pen, and use it to draw a line. DIM pen AS CGpPen = CGpPen(ARGB_RED, 5) graphics.DrawLine(@pen, 0, 0, 200, 100)

' // Change the pen's color to blue, and draw a second line. pen.SetColor(GDIP_ARGB(255, 0, 0, 255)) graphics.DrawLine(@pen, 0, 40, 200, 140)

END SUB ' ========================================================================================
