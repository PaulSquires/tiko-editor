CGpPen.SetDashOffsetmethod

Sets the distance from the start of the line to the start of the first dash in a dashed line.

GraphicsmethodCGpPen.incdocumented

Syntax

FUNCTION SetDashOffset (BYVAL dashOffset AS SINGLE) AS GpStatus

Parameters

NameDescription
dashOffsetThe number of times to shift the spaces in a dashed line. Each shift is equal to the length of a space in the dashed line.

Return value

If the function succeeds, it returns Ok, which is an element of the GpStatus enumeration.

If the function fails, it returns one of the other elements of the GpStatus enumeration.

Description

Sets the distance from the start of the line to the start of the first dash in a dashed line.

Example

' ======================================================================================== ' The following example creates a Pen object, sets the dash style and the dash cap, and ' draws a dashed line. ' ======================================================================================== SUB Example_SetDashOffset (BYVAL hdc AS HDC)

' // Create a graphics object from the window device context DIM graphics AS CGpGraphics = hdc ' // Set the scale transform graphics.ScaleTransformForDpi

' // Create a Pen object DIM pen AS CGpPen = CGpPen(ARGB_BLUE, 15)

' // Set the dash style for the pen pen.SetDashStyle(DashStyleDash)

' // Draw a line using the pen graphics.DrawLine(@pen, 0, 50, 400, 50)

' // Set the dash offset value for the pen, and draw a second line. pen.SetDashOffset(10) graphics.DrawLine(@pen, 0, 80, 400, 80)

END SUB ' ========================================================================================
