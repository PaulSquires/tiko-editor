GdipDeleteFontFamilyfunction

Deletes the specified **FontFamily** object.

Graphicsfunctiondocumented

Syntax

FUNCTION GdipDeleteFontFamily (BYVAL fontFamily AS GpFontFamily PTR) AS GpStatus

Parameters

NameDescription
fontFamily[in] Pointer to the FontFamily object to delete.

Description

Deletes the specified FontFamily object.

Example

DIM hStatus AS LONG

' // Initialize GDI+ DIM token AS ULONG_PTR = AfxGdipInit

' // Create a font family DIM fontFamily AS GpFontFamily PTR hStatus = GdipCreateFontFamilyFromName("Arial", NULL, @fontFamily)

... ... ...

' // Cleanup IF fontFamily THEN GdipDeleteFontFamily(fontFamily)

' // Shutdown GDI+ AfxGdipShutdown token
