GdipGetEncoderParameterListSizefunction

Gets the size, in bytes, of the parameter list for a specified image encoder.

Graphicsfunctiondocumented

Syntax

FUNCTION GdipGetEncoderParameterListSize (BYVAL image AS GpImage PTR, BYVAL clsidEncoder AS CLSID PTR, BYVAL size AS UINT PTR) AS GpStatus

Parameters

NameDescription
image[in] Pointer to the Image object.
clsidEncoder[in] Pointer to a CLSID that specifies the encoder.
size[in] Pointer to a variable that receives the size, in bytes, of the parameter list.

Description

Gets the size, in bytes, of the parameter list for a specified image encoder.

Example

'#CONSOLE ON #define _WIN32_WINNT &h0602 #INCLUDE ONCE "AfxNova/AfxGdiPlus.inc"

DIM hStatus AS LONG

' // Initialize GDI+ DIM token AS ULONG_PTR = AfxGdipInit

' // Load the original image from file DIM image AS GpImage PTR hStatus = GdipLoadImageFromFile("RYDER_Winona_01.jpg", @image)

' // Get the JPEG encoder CLSID DIM clsid AS CLSID = AfxGdipGetEncoderClsid("image/jpeg")

' // Get size of parameter list DIM listSize AS UINT hStatus = GdipGetEncoderParameterListSize(image, @clsid, @listSize) PRINT "Size of parameters list: ", listSize

' // Cleanup IF image THEN GdipDisposeImage(image)

' // Shutdown GDI+ AfxGdipShutdown token

PRINT PRINT "Press any key" SLEEP
