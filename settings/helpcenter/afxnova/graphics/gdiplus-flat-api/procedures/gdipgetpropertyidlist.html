GdipGetPropertyIdListfunction

Gets a list of the property identifiers used in the metadata of the image.

Graphicsfunctiondocumented

Syntax

FUNCTION GdipGetPropertyIdList (BYVAL image AS GpImage PTR, BYVAL numOfProperty AS UINT, BYVAL list AS PROPID PTR) AS GpStatus

Parameters

NameDescription
image[in] Pointer to the Image object.
numOfProperty[in] Integer that specifies the number of elements in the list array. Call the GetPropertyCount method to determine this number.
list[out] Pointer to an array that receives the property identifiers.

Description

Gets a list of the property identifiers used in the metadata of the image.

Example

' ======================================================================================== ' Gets a list of the property identifiers used in the metadata of an Image object. ' ========================================================================================

'#CONSOLE ON #define _WIN32_WINNT &h0602 #INCLUDE ONCE "AfxNova/AfxGdiPlus.inc" USING AfxNova

DIM hStatus AS LONG

' // Initialize GDI+ DIM token AS ULONG_PTR = AfxGdipInit

' // Load the original image from file DIM image AS GpImage PTR hStatus = GdipLoadImageFromFile("climber.jpg", @image)

' // Get the pixel format DIM rguid AS GUID hStatus = GdipGetImageRawFormat(image, @rguid)

' // Get the number of properties DIM count AS UINT hStatus = GdipGetPropertyCount(image, @count) PRINT "Number of properties =" & STR(count)

' // Get the list of properties DIM propIDs(count - 1) AS PROPID hStatus = GdipGetPropertyIdList(image, count, @propIDs(0)) FOR i AS LONG = 0 TO count - 1 PRINT "PROPID: " & HEX(propIDs(i)) NEXT

' // Cleanup IF image THEN GdipDisposeImage(image)

' // Shutdown GDI+ AfxGdipShutdown token

PRINT PRINT "Press any key" SLEEP
