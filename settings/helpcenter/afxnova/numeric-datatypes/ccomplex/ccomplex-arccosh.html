CComplex.ArcCosHmethod

Calculates the inverse hyperbolic cosine.

Numeric DatatypesmethodCComplex.incdocumented

Syntax

FUNCTION ArcCosH (BYVAL x AS DOUBLE) AS DOUBLE

Parameters

NameDescription
xA double value.

Description

Calculates the inverse hyperbolic cosine.

Example

DIM AS double pi = 3.1415926535 DIM AS double x, y DIM cpx AS CComplex x = cosh(pi / 4) y = cpx.ArcCosH(x) print "cosh = ", pi/4, x print "ArcCosH = ", x, y

Output: cosh = 0.785398163375 1.324609089232506 acosh = 1.324609089232506 0.7853981633749999
