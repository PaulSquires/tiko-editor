Description

Initialize the class with the specified value.

  1. Creates an empty Unicode string buffer with an initial null-terminated string.
  2. Initializes a BSTRING instance from a wide string pointer.
  3. Initializes a BSTRING from an ANSI or UTF-8 encoded string, with optional code page support. For a list of code pages see: Code Page Identifiers.aspx)
  1. Creates a copy of an existing BSTRING.
  2. Creates a BSTRING with a fixed-length buffer, initialized with a fill character.
  3. Initializes a BSTRING with a numeric value, allowing automatic conversion.
