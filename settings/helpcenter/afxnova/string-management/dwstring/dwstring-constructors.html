Description

  1. Creates an empty Unicode string buffer with an initial null-terminated string.
  2. Initializes a DWSTRING instance from a wide string pointer.
  3. Initializes a DWSTRING from an ANSI or UTF-8 encoded string, with optional code page support. For a list of code pages see: Code Page Identifiers.aspx)
  1. Creates a copy of an existing DWSTRING.
  2. Creates a DWSTRING with a fixed-length buffer, initialized with a fill character.
  3. Initializes a DWSTRING with a numeric value, allowing automatic conversion.
