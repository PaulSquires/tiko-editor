PRIVATE FUNCTION CWebCtx.GetElementInnerHtmlById (BYREF dwsId AS DWSTRING) AS DWSTRING

Parameters

NameDescription
cbsId= The idenfier.
Astring containing the HTML text. Remarks: This method performs a case insensitive property search. If two or more attributes have the same name (differing only in uppercase and lowercase letters) this function retrieves values only for the last attribute created with this name, and ignores all other attributes with the same name.
