CButton.SetSplitStylemethod

Sets the split style of a split button.

WindowsmethodCButton.incdocumented

Syntax

FUNCTION SetSplitStyle (BYVAL hButton AS HWND, BYVAL uStyle AS UINT) AS BOOLEAN

Parameters

NameDescription
hButtonHandle of the button control.
uStyleThe split button style. Value must be one or more of the following flags:

Return value

Returns TRUE if successful, or FALSE otherwise.

Description

Sets the split style of a split button

Remarks

Use this message only with the BS_SPLITBUTTON and BS_DEFSPLITBUTTON button styles.

Example

CButton.SetSplitStyle(hButton, BCSS_ALIGNLEFT)
