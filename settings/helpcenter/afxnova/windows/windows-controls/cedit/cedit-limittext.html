CEdit.LimitTextmethod

Sets the text limit of an edit control.

WindowsmethodCEdit.incdocumented

Syntax

SUB LimitText (BYVAL hEdit AS HWND, BYVAL chMax AS DWORD)
Also documented as SetLimitText — one description covers them all.

Parameters

NameDescription
hEditThe handle of the edit control.
chMaxThe maximum number of characters the user can enter. This number does not include the terminating null character.

Description

Sets the text limit of an edit control. The text limit is the maximum amount of text, in characters, that the user can type into the edit control.

Example

CEdit.LimitText(hEdit, 50) CEdit.SetLimitText(hEdit, 50)
