CListView.GetNextItemmethod

Searches for a list-view item that has the specified properties and bears the specified relationship to a specified item.

WindowsmethodCListView.incdocumented

Syntax

FUNCTION GetNextItem (BYVAL hListView AS HWND, BYVAL iStart AS LONG, BYVAL flags AS UINT) AS LONG

Parameters

NameDescription
hListViewHandle to the ListView control.
iStartThe index of the item with which to begin the search, or -1 to find the first item that matches the specified flags. The specified item itself is excluded from the search.
flagsThe geometric relation of the requested item to the specified item and, if specified, the state of the requested item. For a list of possible values, see the description of the lParam parameter in the LVM_GETNEXTITEM message. If an item does not have all of the specified state flags set, the search continues with the next item.

Return value

Returns the index of the next item if successful, or -1 otherwise.

Description

Searches for a list-view item that has the specified properties and bears the specified relationship to a specified item.
