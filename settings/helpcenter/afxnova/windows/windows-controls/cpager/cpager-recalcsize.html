CPager.RecalcSizemethod

Forces the pager control to recalculate the size of the contained window.

WindowsmethodCPager.incdocumented

Syntax

SUB RecalcSize (BYVAL hPager AS HWND)

Parameters

NameDescription
hPagerHandle to the pager control.

Description

Forces the pager control to recalculate the size of the contained window. Using this macro will result in a PGN_CALCSIZE notification being sent.

Example

CPager.RecalcSize(hPager)
