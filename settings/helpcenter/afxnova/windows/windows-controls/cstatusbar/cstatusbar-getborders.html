CStatusBar.GetBordersmethod

Retrieves the current widths of the horizontal, and vertical borders of a status window, and the width of the border between rectangles.

WindowsmethodCStatusBar.incdocumented

Syntax

FUNCTION GetBorders (BYVAL hStatusBar AS HWND, BYVAL rgBorders AS LONG PTR) AS LONG

Parameters

NameDescription
hStatusBarThe handle of the status bar control.
rgBordersPointer to an integer array that has three elements. The first element receives the width of the horizontal border, the second receives the width of the vertical border, and the third receives the width of the border between rectangles.

Return value

Returns TRUE if successful, or FALSE otherwise.

Description

Retrieves the current widths of the horizontal, and vertical borders of a status window, and the width of the border between rectangles.

Remarks

The borders determine the spacing between the outside edge of the window and the rectangles within the window that contain text. The borders also determine the spacing between rectangles.
