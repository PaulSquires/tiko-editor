CTextStory.GetTextmethod

Gets the text in a story according to the specified conversion flags.

Windowsmethoddocumented

Syntax

FUNCTION GetText (BYVAL Flags AS LONG) AS DWSTRING

Parameters

NameDescription
FlagsThe conversion flags. A Flags value of 0 retrieves text the same as ITextRange.GetText. Other values include the following: tomAdjustCRLF, tomAllowFinalEOP, tomFoldMathAlpha, tomIncludeNumbering, tomNoHidden, tomNoMathZoneBrackets, tomLanguageTag, tomTextize, tomTranslateTableCell, tomUseCRLF.

Return value

The text in the story.

Description

Gets the text in a story according to the specified conversion flags.

Remarks

This method is similar to using ITextRange2.GetText2 for a whole story, but it doesn’t require a range.
