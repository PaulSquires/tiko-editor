CMaskedEdit.SetValidCharsmethod

Specifies a string of valid characters that the user can enter.

WindowsmethodCMaskedEdit.incdocumented

Syntax

SUB SetValidChars (BYVAL lpszValid AS WSTRING PTR)

Parameters

NameDescription
lpszValidA string that contains the set of valid input characters. NULL means that all characters are valid. The default value of this parameter is NULL.

Description

Specifies a string of valid characters that the user can enter.

Remarks

Use this method to define a list of valid characters. If an input character is not in this list, masked edit control will not accept it.

The following code example accepts only hexadecimal numbers.

Example

pMskEd.EnableMask(" AAAA"), _ ' // Mask string ("0x____"), _ ' // Template string ("_") ' // The default character that replaces the backspace character pMskEd.SetValidChars("1234567890ABCDEFabcdef") ' // Valid string characters pMskEd.SetText("0x01AF"), TRUE
