AfxRightJustifyMenuItemfunction

Right justifies a top level menu item.

Windowsfunctiondocumented

Syntax

FUNCTION AfxRightJustifyMenuItem (BYVAL hMenu AS HMENU, BYVAL uItem AS DWORD) AS BOOLEAN

Parameters

NameDescription
hwndHandle to the window that owns the menu.
uItemThe zero-based position of the top level menu item to justify.

Return value

If the function succeeds, the return value is TRUE. If the function fails, the return value is FALSE.

Description

Right justifies a top level menu item.

Remarks

This is usually used to have the Help menu item right-justified on the menu bar.
