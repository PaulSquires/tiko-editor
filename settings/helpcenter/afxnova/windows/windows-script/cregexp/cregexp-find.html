CRegExp.Findmethod

Find function with VBScript regular expressions search patterns.

WindowsmethodCRegExp.incdocumented

Syntax

FUNCTION Find (BYREF wszSourceString AS CONST WSTRING) AS LONG
FUNCTION Find (BYVAL nStart AS LONG, BYREF wszSourceString AS CONST WSTRING) AS LONG

Parameters

NameDescription
nStartThe position in the string at which the search will begin. The first character starts at position 1.
wszSourceStringThe string to be parsed.

Return value

Returns the position of the match or 0 if not found. The length of the match can be retrieved calling the MatchLen property.

Description

Find function with VBScript regular expressions search patterns.

Examples

DIM pRegExp AS CRegExp DIM dwsText AS DWSTRING = "blah blah a234 blah blah x345 blah blah" pRegExp.Pattern = "[a-z][0-9][0-9][0-9]" DIM nPos AS LONG = pRegExp.Find(dwsText) PRINT nPos ' Output: 11

DIM pRegExp AS CRegExp DIM dwsText AS DWSTRING = "blah blah a234 blah blah x345 blah blah" pRegExp.Pattern = "[a-z][0-9][0-9][0-9]" DIM nPos AS LONG = pRegExp.Find(15, dwsText) PRINT nPos ' Output: 26
